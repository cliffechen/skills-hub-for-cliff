# 示例产出

`04-示例产出/` 是 UA700 项目（Amazon US，ASIN B0XXXXXXXX，ZAB Urolithin A 700mg，90 粒 / 45 份）用 `scripts/build_xlsx.py` 生成的两份成品交付表，用来对照交付格式：

| 文件 | 输入 | 规模 |
|---|---|---|
| `B0XXXXXXXX_A+与品牌故事文案_v1.xlsx` | 6 张 A+ / 品牌故事构图 | 56 个文字位 + 1 行 Alt 文本 / 14 条设计修改 / 15 条事实 |
| `B0XXXXXXXX_副图文案_v1.xlsx` | 8 张 1600×1600 副图 | 39 个文字位 / 14 条设计修改 / 16 条事实 |

每个文件 4 个 sheet：**说明**（含本次确认的决定与规则卡摘要）、**文案总表**（每行 = 一个文字位；E 列新英文文案、F 列备选句、G 列中文释义、H–J 列字符数用 LEN 公式、K 列占位原文、L 列事实编号、M 列合规/设计备注）、**设计修改清单**（必改/建议/确认三档）、**事实依据**（F01… 及出处）。

这两份是早期版本，写法已经被 `references/conversion-copy.md` 和 `references/brand-profiles/zab.md` 取代；只看格式，不当文案范本。

构图、对标品牌库等输入不进仓库（体积大，对标素材版权归原品牌），用的时候放进本地 `工作区/`，见 `CLAUDE.md`。
