# 读者阶段、钩子与两个维度的版本

回答三个问题：这组图主要写给哪种读者；每张图的画面和文字各说什么；多版文案按什么分。plan 的「买家与主线」「逐图任务卡」「每个文字位写几版」都按这里来。

方法改写自 coreyhaines31/marketingskills（MIT）的 `ad-creative`（认知阶段标题、钩子系统、证据输入），按亚马逊图片文案删改；未照搬原文。

## 0. 先认清一个限制

一个 ASIN 只有一套副图和一套 A+，所有访客看到的都一样，**不能按搜索词给不同的人看不同的图**。所以这里的“版本”是整组图的假设：按主流量选一版做整组；流量够了，再用后台的实验功能拿另一版来比，一次只换一个变量。

## 1. 读者的认知阶段

| 阶段 | 典型搜索词 | 读者需要什么 | 适合的写法 |
|---|---|---|---|
| 已认品牌或已认本品类的换牌者 | 头部品牌词、“品牌 + 型号” | 用具体证据打消一个疑问 | 有据数字、痛点＋结果、读者自己的问题 |
| 懂方案，在比较做法 | 成分词、“成分 + 剂量 / 剂型” | 看清本品的做法具体哪里不同 | 状态变化、有据数字 |
| 知道问题，还没选方案 | 需求词、人群词（calcium supplements for women） | 看到一条可信的出路 | 感受、痛点＋结果、时间点上的麻烦 |
| 还没意识到问题 | 很少来自站内搜索，多为站外 | 认出一个自己的处境 | 感受、对话 |

**怎么定主阶段**：看产品上下文里的主搜索词和广告策略。品牌词截流 → 换牌者；成分词 → 懂方案；人群词和需求词 → 知道问题。数据不够时写明这是假设，并给出两个阶段各一版。

## 2. 六种写法

下面的例句只示范结构，是编的，不是可用文案；数字和说法要换成本品事实。

| 写法 | 怎么搭 | 示范 | 注意 |
|---|---|---|---|
| 感受 | 一个具体生活时刻里的感受 | The Calcium You Keep Meaning to Take. | 不写空泛的“赋能” |
| 对话 | 两行来自真实处境的话；送礼位写收礼人 | For the Parent Who Keeps Forgetting Calcium. | 不编造带署名的买家评价 |
| 状态变化 | 把换过来之后具体变成什么样摆出来 | One Bottle Where Several Used to Sit. | 不写成 Not X, Y；不点名对手 |
| 时间点上的麻烦 | 点出一个重复、过时的做法和它发生的时刻 | 每天早上先数四粒 | 说做法，不说买家笨 |
| 有据数字 | 一个有出处的数字，带对象和份量基准 | 400 mg, 31% of Your Daily Value. | 数字照标签，不四舍五入成好看的数 |
| 痛点＋结果 | 一个点名的麻烦加一个具体结果 | Two Softgels a Day. That Is the Whole Serving. | 短不是省掉限定语的理由 |

读者自己会问的问题可以直接当标题（Switching Brands? Read the Test Results.），也可以做成问答表。给自己的卖点设问再自答（The result? ……）不行，见 `edit-sweeps.md`。

## 3. 画面和文字各说一半

一张图的钩子是两个部件：**画面**和**标题**。两者要互补，不能重复。

- 画面已经摆出六个剂量，标题就不要再写 “6 Actives. Every Dose Stated.”，那只是把图念一遍。改成读者拿这些数字做什么：Check Every Amount Before You Switch.
- 照片是在跑步的人，标题就不要写 “Made for Every Active Day”。
- 第 3 步读构图时，每页记一句“画面已经在说什么”；第 5 步写标题时，写画面没说的那一半。任务卡里列两栏：画面负责 / 标题负责。
- 小图检查：副图在手机搜索结果和详情页缩略图里很小，标题要在实际显示大小下读得清；读不清就缩短说法或改版式，不靠缩小必要的限定语。

## 4. 证据表：说法的证据和功效的证据是两回事

写之前先把证据列出来，进事实底座（E 编号，和 F 编号放同一张「事实依据」表）：

| 字段 | 内容 |
|---|---|
| 编号 | E01…… |
| 类型 | 语言 / 痛点 / 反对意见 / 缺口 |
| 来源 | 本品评论、竞品 1–3 星评论、竞品 4 星评论、问答区 |
| 内容 | 转述成短语，不大段照抄 |
| 频次 | “8 / 15 条”这样写，注明抽样范围 |
| 怎么用 | 可借用说法 / 不能当功效依据 / 需用户确认 |

- **语言证据**（评论里说“每天要吃一摞”）只支撑一个角度和用词，不支撑任何功效或数字承诺。
- **事实证据**（标签、证书、检测报告）才能支撑上图的数字和认证。
- 评论里提到但标签和用户都没确认的产品细节（瓶子材质、封口方式、口感），不上图，进③待确认。
- 缺的事实写进“缺口”一行，文案里用到它的地方先不写，见 `edit-sweeps.md` 的 `[NEED: …]` 规则。

## 5. 钩子矩阵

按“人群 → 动机 → 写法 → 画面和标题”自上而下生成，写进 JSON 的 `hooks`，Excel 出「钩子矩阵」表。

| 人群 | 认知阶段 | 动机（证据编号） | 写法 | 画面负责 | 标题负责 | 用在 |
|---|---|---|---|---|---|---|

- 一行是一个“人群 × 动机”的格子。要的是格子多，不是同一个格子改写三十遍。
- 每行都有证据编号；没有出处的钩子不写。
- 一组图里各张图的开头句式要有变化：十张图同一种开头，单看每张都没错，放在一起就像生成的。

## 6. 两个维度的版本

用户要多版文案时，两个维度都保留（用户 2026-10-13）：

**维度一：读者版本（A / B / C）**——每版是一个整组假设，对应一个认知阶段。在 plan 里写清每版写给谁、哪版是主版本。

**维度二：功效档位（标准 / 保守）**——每个产品在 plan 里定出“敏感功效词”（类目审核容易卡、或用户内部规则默认拦截的方向，例如骨骼类产品的 bone），写进 `meta.claims.sensitive`。

- 每个读者版本按它自然的写法写，这是**标准档**。
- 标准档里凡是出现敏感功效词的文字位，都另给一行**保守档**：同一文字位、不含敏感词，只写事实或隐喻。文字位名称写成 `【A·保守】标题`。
- 标准档本来就不含敏感词的文字位，不用写保守行。
- 这样美工先选读者，再按风险偏好逐个文字位决定用标准还是保守。

JSON 写法：

```json
"meta": {
  "versions": [
    {"key": "A", "reader": "换牌者", "stage": "已认品牌", "main": true},
    {"key": "B", "reader": "成分党", "stage": "懂方案"},
    {"key": "C", "reader": "刚开始在意的人", "stage": "知道问题"}
  ],
  "claims": {"allowed": ["…"], "blocked": ["…"], "sensitive": ["bone"]},
  "swap_terms": ["calcium", "algae", "softgel", "urolithin"]
},
"rows": [
  {"id": "P2-01", "page": 2, "slot": "【A】正文", "copy": "Algae calcium supports bone health, and vitamin D3 helps your body absorb it.*"},
  {"id": "P2-02", "page": 2, "slot": "【A·保守】正文", "copy": "400 mg algae calcium per serving, with vitamin D3 to help your body absorb it.*"}
]
```

行的顺序：A 全部 → A·保守 → B 全部 → B·保守 → C…… → 共用。`scan_copy.py` 会检查：保守行里出现 `sensitive` 里的词即 FLAG。备注格式见 `canva-notes-format.md`「多版文案」。

## 7. 整组里每张图回答谁的什么

定了主版本之后，每张图仍要各回答一个疑问（`conversion-copy.md` §7 的顺序照用）。产品上下文里的每条反对意见 O1、O2……至少在一张图上被事实回答；任务卡里标出是哪一张。弱项如实写：钙量只占每日参考值的 31%，就把 31% 写在图上，不回避。
