# 从任意品牌 markdown 集提炼"规则卡"

对标库可能是任何品牌、任何目录结构。目标是用最少的阅读量拿到可复用的**方法**，而不是原句。

## 阅读顺序

1. `Glob **/*.md` 列出全部文件，先读 README / index / 目录类文件，理解库的结构和作者对"观察/分析/模板"的区分。
2. 优先读（按文件名或目录名判断）：
   - 写作规则、语气、词汇模式、定位（如"规则""语气""定位""voice""tone"）
   - 可复用模板、Brief 模板
   - 亚马逊 A+ / 图片构图 / 品牌故事拆解（如"A+""A加""Brand Story""图片与构图"）
   - 证据/成分表达、信任/订阅/CTA 表达
3. 按需读：逐产品拆解（挑一个与当前产品最接近的即可）、视觉规律、教育文章。
4. 跳过：素材清单、哈希/校验、采集缺口、覆盖表等纯索引文件。

## 规则卡（≤12 条，每条注明来源文件）

| 字段 | 要回答的问题 |
|---|---|
| 叙事顺序 | 对标 A+ 从第一张到最后一张的问题链是什么？ |
| 开场方式 | 情绪句 / 顾客心声问句 / 痛点？ |
| 数字写法 | 数字如何带对象、单位、份量？有无"两种数字并列辨析"？ |
| 成分组织 | 主成分＋辅助的分工怎么讲？ |
| 对比写法 | 对比表的对象、行数、视觉符号；有无被库作者标注为风险的写法？ |
| 场景写法 | 生活场景如何分配利益？ |
| 信任收尾 | 标签、检测、认证、保证政策的层次 |
| 品牌故事 | 卡片顺序与每张卡的任务 |
| 语气词汇 | 常用词、句长、标点习惯 |
| 合规边界 | 库作者明确说"不宜复制"的说法（如100%吸收、保证体感） |
| 视觉-文案关系 | 图上字数、层级、小屏风险 |

## 使用边界

- 对标品牌的具体主张（检测、功效、保证期限）属于**对方的事实**，不能迁移到当前产品。
- 库里标为"分析/推断"的内容当作参考，不当作规则；标为"风险/边界"的内容进入合规检查。
- 规则与本产品事实冲突时，以事实为准，并在 plan 中说明取舍。
