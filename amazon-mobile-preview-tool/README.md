# Canva → 亚马逊手机预览工具

在 Canva 里做图，在这个窗口里检查手机浏览效果。所有项目和素材都保存在本机。

这是可直接运行的本地预览工具。它与仓库中的 [amazon-copy-writing-project 文案工作台](../amazon-copy-writing-project/) 同属 **Amazon Design**：文案工作台用于写稿、改稿；本工具用于检查成稿图片在手机上的排版、轮播和视频效果。

## 启动

Windows 双击 **启动预览工具.bat**。启动窗口会显示网址并打开默认浏览器；保留启动窗口，关闭它会停止服务。

需要 Python 3.10 或更新版本，无需安装任何第三方 Python 包或前端依赖。从 GitHub 下载或克隆仓库后，进入 `amazon-mobile-preview-tool` 文件夹再启动。默认使用 `http://127.0.0.1:8877`；端口被占用时自动选择后续可用端口。

macOS / Linux 可在本工具目录执行 `bash 启动预览工具.sh`；各平台也可以执行 `python server.py`（部分系统使用 `python3 server.py`）。仓库附带“示例 · 现有设计稿”，首次打开即可预览；点击“新建项目”可保存自己的产品。

如果编辑过启动脚本后提示 `rorlevel` 或其他被截断的命令“不是内部或外部命令”，请检查 `.bat` 是否保存为 **UTF-8（无 BOM）和 Windows CRLF 换行**。项目中的启动脚本已使用此格式，`.editorconfig` 也规定了该格式，避免编辑时被改成 LF。

## 常用操作

1. **新建项目**：每个产品单独保存，可在顶部切换或重命名。
2. **导入主副图**：点击“添加主副图”，支持一次选择多张 PNG、JPG、WebP。
3. **添加品牌故事与 A+**：在“品牌故事”分区点击“＋ 添加品牌故事”；在“A+ 模块”分区选择“整张图片”“高级轮播”或“全宽视频”。
4. **快速换图**：单击素材槽使其高亮，再按 `Ctrl+V` 粘贴截图；也可拖入文件，或点击“替换”。截图应只包含单张设计区域。
5. **检查浏览**：滚轮在手机画面里上下滚动，按住鼠标左右拖动切图，或点击轮播标签。聚焦轮播后也可以按左右方向键。

批量图片放入整图槽：第一张替换当前槽，其余新增为后续整图模块。批量图片放入轮播项：第一张替换当前项，其余依次插入。轮播的“批量导入轮播图片”会追加新项。

使用拖动手柄或上下箭头调整顺序。“×”删除位置；“清空素材”只清空图片，保留位置与文字。轮播的标签在工具里单独填写；已画进图片的文字无需重复填写。

鼠标悬停左侧素材卡片时，用 `#FFA41C` 橙色高亮。点击 A+ 卡片标题、空白处或图片槽，会定位右侧对应模块并快速闪烁两次；点击轮播图片槽还会切换到对应轮播项。卡片标题支持键盘 Enter / 空格定位。系统开启“减少动态效果”时，闪烁改为短暂静态高亮。

全宽视频分别导入 MP4 和可选封面。浏览器支持的 H.264 / AAC MP4 兼容性较好；此工具不做转码。支持原生播放、暂停和进度拖动，不自动播放。

### From the brand · 品牌故事

点击“品牌故事”分区中的 **＋ 添加品牌故事**，会在现有 A+ 内容前插入品牌故事模块，并提供两个空白卡片槽。右侧显示 “From the brand” 标题、品牌背景和可横向滑动的竖版卡片，旁边露出下一张卡片。品牌故事和普通 A+ 分别在各自分区内排序，预览中品牌故事始终位于普通 A+ 前面。

左侧“主图与副图”分区使用 `#24333F` 底色，“品牌故事”分区使用 `#242321` 底色，与普通 A+ 模块清楚区分。

- **品牌名称 / Logo**：填写品牌名称，或导入 Logo 图片；有 Logo 时优先显示 Logo。
- **背景图**：可选，铺满卡片后方的整个品牌区域；不导入时使用深色背景。
- **品牌卡片**：逐张导入，也可批量选择图片。图片在约 4:5 的竖卡预览框里完整等比显示，已画入图片的标题、正文无需重复填写；需要时可以展开“图片外的标题与正文”补充文字。
- **浏览和编辑**：左右拖动或聚焦后用左右方向键切卡；支持粘贴、拖入、替换、清空、增加、排序和删除卡片。点击左侧卡片会定位右侧对应卡片并闪烁两次。

背景、Logo 和卡片均保存在当前项目的 `assets/aplus/`，项目与阅读位置会自动保存。请分别导入背景和单张卡片设计稿；截图仅作为排版参考，工具不会自动拆分截图。此布局用于设计预览，4:5 是预览框比例，不代表 Amazon 官方上传规格。

## 窄窗口与显示尺寸

顶部右侧按钮收起编辑区，可把预览窗口放到 Canva 旁边。窄窗口中展开编辑区会显示覆盖式抽屉，再次点击按钮即可收起。

视口有 360×780、390×844、430×932 三档。**视口决定排版，缩放只决定在电脑上显示多大**；100% 表示 CSS 像素比例，不代表显示器上的物理尺寸与真手机相同。“适应窗口”会完整显示手机画布。

“Amazon 外观”可以切换简化商品页与纯内容。点击“主副图”“A+ 页面”快速跳转。替换图片会保留当前模块与轮播项；图片高度改变时尽量保留模块内相对位置。

## 保存与备份

修改会自动保存，也可以按 `Ctrl+S`。离开页面前确认顶部显示“已保存在本机”。保存失败时保留窗口，点击“重试保存”；不同窗口产生版本冲突时，可将当前草稿及素材另存为独立副本。

数据位于本目录的 `data/<项目名称>/`，直接按项目名称找文件夹即可，不需要记随机 ID。当前示例项目的路径是：

```text
amazon-mobile-preview-tool/
└─ data/
   └─ 示例 · 现有设计稿/
      ├─ project.json
      └─ assets/
         ├─ main/          ← 主图与副图
         ├─ aplus/         ← A+ 图片、轮播、视频和封面
         └─ catalog.json
```

在文件资源管理器中打开工具所在文件夹，依次进入 `data` → `示例 · 现有设计稿` → `assets`，就能找到 `main` 和 `aplus`。也可以直接打开 [主副图文件夹](<data/示例 · 现有设计稿/assets/main/>) 或 [A+ 素材文件夹](<data/示例 · 现有设计稿/assets/aplus/>)。

新项目会使用创建时的项目名称作为文件夹名；同名项目自动添加 ` (2)`、` (3)` 等编号，不能用于 Windows 文件名的字符会自动处理。页面中重命名项目只更改显示名称，磁盘文件夹保留创建时的名称，便于已有路径和备份继续使用。

旧版的随机 ID 文件夹（例如 `9c46c5c8a32941169b1734456fcb5e6e`）会在启动新版服务时自动迁移成项目名称。项目 ID 仍保留在 `project.json` 内供程序关联使用；原有项目、素材和浏览器里的项目选择继续有效。

各文件的用途：

- `project.json`：商品信息、主副图、模块、文字、设置和阅读位置。
- `assets/main/`：主图与副图的素材副本。
- `assets/aplus/`：A+ 整图、轮播图、视频和封面。
- `assets/catalog.json`：素材索引，记录原文件名与分类；磁盘文件使用唯一 ID 命名，避免同名图片互相覆盖。

启动新版服务时，现有项目中正在使用的旧素材会自动归类，页面中的图片引用保持不变。历史导入但已不再使用、无法判断分类的旧文件仍保留在 `assets/` 根目录。此后通过选文件、粘贴、拖入、批量导入或另存副本导入的素材都会按用途分目录存放。

备份整个 `data` 文件夹即可。移除页面上的图片不会删除原设计稿，也不会自动清理历史导入文件。不要在服务运行时手工更改数据文件。

Git 仓库保留工具源码和上述示例项目；新建的个人项目、本地 `backups/`、运行日志和缓存默认由 `.gitignore` 忽略。`.gitattributes` 会让 Windows 启动脚本在克隆后保持 CRLF 换行，其他平台的启动脚本保持 LF。

## 规格参考与边界

| 模块 | 手机图片 / 视频 | 桌面图片 / 封面 |
| --- | --- | --- |
| Premium Full Image | 600×450，4:3 | 1464×600 |
| Premium Navigation Carousel | 每张 600×450，4:3 | 每张 1464×600 |
| Premium Full Video | 视频最低 960×540，手机复用素材 | 独立封面最低 1464×600 |

来源：[Amazon Premium A+ Module Guide](https://m.media-amazon.com/images/G/01/BX_Marketing/2023/AMZ_Guide_Premium_A_Module_05b.pdf)，2023-05-30，第3、9、16页。指南标注的是最低规格，不表示其他比例一概不能上传。1800×1350 与 600×450 都是 4:3。比例不同的草稿会完整等比显示并提示。

v0 用于设计检查，不提交到 Amazon，不连接 Canva 账户，不自动裁切或拆分截图。手机外观参考提供的录屏，不能替代发布后对实际 Amazon 前台的核验。

## 开发与检查

```powershell
python server.py --no-browser
python -m unittest discover -s . -p test_server.py -v
```

可选参数：`--port 8877` 指定端口，`--data-dir 路径` 使用独立测试数据目录。

前端没有构建步骤或网络依赖。`app.js` 管理编辑、导入、自动保存；`preview.js` 管理手机渲染、轮播和阅读位置。后端测试覆盖持久化、并发保护、原子保存失败、损坏上传、同名素材、视频 Range/HEAD 和访问边界。
