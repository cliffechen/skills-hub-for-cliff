# 报告结构（MECE，七章）

对每一章节，不要只是罗列标题——把下面列出的每个子问题都实际回答到。缺一个子问题都会让报告显得像模板而非深度分析。全程用【产品】【目标市场】【商业模式】代指用户在第一步给定的具体产品、具体市场和具体商业模式，替换成真实内容。

第四章和第六章明确标了 B2B / B2C 分支写法——只写用户指定的那个商业模式对应的分支；如果用户选了"两者皆有"，两个分支都要写，且要分开呈现、不要混在一起讲（比如先讲经销商渠道的客户画像，再单独讲终端消费者画像，不要试图用一套语言同时描述两种完全不同的决策逻辑）。

## 一、执行摘要

- 用 3-5 句话概括【目标市场】【产品】的核心吸引力与最大风险。不要写"市场很大、机会很多"这类空话——要具体到只影响这一个产品在这一个市场的核心变量。
- 提炼 3 个最具颠覆性的市场洞察。颠覆性 = 换成任何其他产品或市场都不成立的判断，而不是行业常识。
- 给出 3 条黄金行动建议，分别面向：中国出口企业自己 + 当地 B2B 客户。建议要具体到"接下来该做什么"，不是方向性描述。

## 二、宏观环境与市场底盘（PESTEL + 逻辑树）

- **政治与合规**：【目标市场】针对【产品】品类的准入认证（列出具体认证名称）、关税壁垒（具体税号/税率，如有反倾销税要点名）、环保/ESG 要求、政策倾斜（补贴、以旧换新等）。
- **经济与周期**：汇率波动对采购决策的实质影响（不是泛泛提"汇率风险"，而是量化到"汇率每变动 X% 对当地采购商到岸成本的影响"）、通胀对该品类采购周期的影响、当地采购力变化趋势。
- **社会与技术**：人口结构变迁（老龄化/城市化/新建 vs 翻新住房比例等）如何改变该产品的需求结构、技术迭代（AI/物联网/能效标准升级等）对产品形态的底层影响。

如果【目标市场】是多国组合，这一章必须对每个子国家分别过一遍这三块，不能用"整体如何如何"含糊带过。

## 三、市场规模与竞争格局（3-5 年预测）

- **市场盘子**：当前市场规模（TAM，标注数据源类型），未来 3-5 年 CAGR，用逻辑树把增长拆到最细颗粒度——是增量需求驱动（新建/新增用户）还是存量替换驱动（以旧换新/技术升级）？这两种驱动力对应完全不同的打法，必须拆开说清楚。
- **竞争格局**：当地本土品牌、国际巨头、中国同行各自的市占率现状（给估算区间也可以，但要标注是估算）。识别出"脆弱的领先者"（市占率高但护城河弱、容易被切走份额的玩家）和"未被满足的利基市场"（具体是哪类细分需求没人认真做）。
- **供应链断层**：当地供应链在哪些环节严重依赖进口、或本土产能效率低下？这对中国出口方是什么机会窗口？

## 四、目标客户深度画像与需求拆解（JTBD 理论驱动）

**如果【商业模式】是 B2B：**

- **目标客户分层**：按规模/商业模式分成 3-4 类（比如大型连锁分销商、工程集成商、OEM/ODM 代工厂、独立中小经销商——具体分几类、怎么分要贴合【产品】和【目标市场】的真实渠道结构，不要套用通用模板）。
- **痛点与待办任务**：每一类客户当前最头痛的业务瓶颈是什么？他们采购【产品】时真正想完成的"任务"是什么——不只是买产品，而是买流量、买利润、买可靠性、买合规、买省心。用 JTBD 语言（"当我___的时候，我想要___，以便于___"），而不是"客户希望产品质量好"这类泛泛表述。
- **决策链路**：典型采购决策链上的发起者、评估者、拍板者分别是谁，各环节有什么没说出口的隐性诉求（比如采购经理怕背锅、老板怕现金流压力）。

**如果【商业模式】是 B2C：**

- **目标消费者分层**：按生活方式/购买动机/使用场景分成 3-4 类细分人群，不要只用年龄性别收入这类人口统计学标签拼一个模板画像——要写清楚这群人为什么会买【产品】、在什么场景下买、跟同类人群的购买行为有什么真实差异。如果销售要经过零售/电商渠道（B2B2C 结构），额外单独画一类"渠道买手/采销"画像，因为他们是第一道决策关卡，需求和终端消费者不同（他们要的是好卖、好周转、好毛利，不是产品本身的使用体验）。
- **痛点与待办任务**：每一类消费者当前的核心购买动机和顾虑是什么？他们买【产品】时真正想完成的"任务"是什么——不只是拥有产品，可能是买省心、买信任（品牌/认证背书）、买身份认同、买效果、买性价比，具体是哪几项要结合产品本身判断，不要照抄这个列表。用 JTBD 语言（"当我___的时候，我想要___，以便于___"）。
- **购买旅程**：从认知到比价、决策、复购的典型路径是什么，线上/线下哪些触点在起决定作用，家庭成员/社交圈/网红测评这类隐性影响者扮演什么角色。

**如果【商业模式】是"两者皆有"：** 按上面两个分支分别完整写一遍，标题上明确区分（如"渠道客户画像"与"终端消费者画像"），不要合并成一段模糊表述。

## 五、产品与功能需求洞察（从趋势到落地）

- **核心功能演进**：未来 3-5 年该产品的基础功能（不满足会被直接淘汰）、期望功能（客户默认应该有）、兴奋型功能（有则加分、能建立差异化）——KANO 模型视角，三档都要给出具体功能点，不是抽象描述。
- **本土化定制需求**：颜色/尺寸/电压/接口/语言/包装等必须本地化适配的具体项，以及当地的"文化雷区"（什么样的设计/宣传/包装元素在当地会引发负面观感）。
- **利润款与引流款设计**：基于当地价格敏感度，哪些型号该做敲门砖（引流款，低毛利换渠道进入）、哪些型号该做盈利核心（高溢价款），给出具体的产品/型号建议逻辑。

## 六、销售渠道与 GTM 进入策略

**如果【商业模式】是 B2B：**

- **渠道解剖**：主流 B2B 销售渠道占比拆解（线下批发、专业展会、B2B 电商平台、直销等），各渠道典型账期、利润分配惯例。
- **生态赋能**：如何让当地代理商/分销商不只是"卖货"，而是能和出口方共建本地护城河（比如联合库存、联合营销、数据回流）？
- **营销触达**：当地最有效的 B2B 获客媒介与信任背书方式（行业媒体、KOL、权威认证背书等，给具体渠道名称）。

**如果【商业模式】是 B2C：**

- **渠道解剖**：主流 C 端销售渠道占比拆解——综合电商平台（如 Amazon、Walmart、MercadoLibre，视目标市场而定）、独立站/DTC、线下零售（大卖场、专卖店、家居建材连锁等）、社交电商/直播带货，各渠道典型平台佣金、退货率、履约成本差异要点出来，不要只列渠道名称不谈经济账。
- **生态赋能**：如果走零售/电商分销，如何帮渠道伙伴做好陈列、内容素材、复购运营？如果是自营独立站/DTC，如何把首批消费者变成复购者和自然传播者（比如私域运营、会员体系、UGC 激励）？
- **营销触达**：当地最有效的 C 端获客媒介与信任背书方式（社媒 KOL/达人测评、搜索广告、联盟营销、平台内广告等，给具体渠道名称，并结合搜索到的实际数据说明获客成本量级）。

**如果【商业模式】是"两者皆有"：** 两个分支分别写，并额外说明两条渠道之间是否会互相冲突（比如独立站和线下经销商的价格体系打架），以及出口方该如何做渠道管控（如 MAP 价格管理）来避免左右手互搏。

## 七、行动蓝图与风险对冲

- **0-12 个月进入战术表**：从样品测试、资质认证、首单破冰到批量出货的时间轴与关键里程碑，给出可执行的月度节点，而不是"第一阶段/第二阶段"这种模糊分期。
- **联合增长计划**：给当地客户一套能直接抄的本地化营销话术与卖点提炼——这部分要写得像可以直接复制粘贴去谈客户的销售物料，而不是内部战略语言。
- **灰犀牛与黑天鹅**：列出 3 个最可能毁掉这门生意的风险（地缘摩擦、反倾销、技术突变等，要具体到【产品】+【目标市场】的真实风险，不是通用商业风险清单），每个风险配一个对应的 Plan B。
