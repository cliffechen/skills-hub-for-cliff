# 基线写作规则（无对标库时使用；有对标库时作为兜底）

1. **一图一任务**：每张图只回答消费者一个问题（这是什么/为什么需要/凭什么信/怎么用/敢不敢买）。
2. **数字四要素**：每个数字写清对象、单位、份量基准、来源。例："700mg Urolithin A per 2-capsule serving"，不写孤立的"700mg"。不同类型的数字不能互相替代（原料量≠有效量，每份≠每粒）。
3. **主成分＋辅助**：先立主角，再解释辅助项各自的角色；单一成分产品用"来源/剂量/配方载体/用法"四格代替成分墙。
4. **A+ 顺读叙事**：问题/情绪开场 → 机制或选择标准 → 对比或核对 → 生活场景 → 信任收尾（标签、认证、服务）。每张图用问句或转折句承接上一张，不要每张都从零介绍产品。
5. **对比要有具体对象**：不写泛指的"OTHERS/普通产品"。改为按属性定义的对照（如"VAGUE LABELS：剂量藏在复合配方里"），左栏保持中性灰字，避免贬损竞品。
6. **食物/自然图只作视觉隐喻**，不暗示是原料来源——除非标签确实如此。
7. **品牌故事卡片**：使命 → 生活方式 → 订阅/复购 → 使用小贴士 → 品质支柱。订阅卡不写未经确认的折扣数字；使命卡写真实创立信息，没有就写品牌主张并提示用户补充。
8. **字数贴版**：新文案行数和字符数贴近占位原文；手机端（A+ 移动图约 600px 宽）最小字仍可读。
9. **不写**：保证效果、绝对化最高级（best/#1）、无证据的百分比、治疗/治愈类说法、未确认的认证。
10. **Logo 与品牌名**以 listing 品牌字段和实物包装为准，设计稿里的品牌字样一律视为占位。
