# Listing 主图 / 副图规则与规格（美国站）

A+ 和品牌故事之外，listing 图库（主图＋最多 8 张副图/视频位）是第二类图片文案任务。写法与 A+ 不同，本附录只写差异。

#### 规格

| 项 | 要求 |
|---|---|
| 尺寸 | 正方形，最长边 ≥1600px（可缩放），常用 1600×1600 / 2000×2000；文件名或比例为 1:1 即判为 listing 图 |
| 主图 | 纯白底（RGB 255,255,255），产品占画面 ≥85%，**不允许**任何文字、Logo（包装自带的除外）、徽章、示意图、非实物道具。主图没有文案任务，除非用户要求写包装/瓶身文字 |
| 副图 | 允许文字、场景、信息图；桌面端默认只显示前 7 张缩略图，之后需点开；有视频时视频占一格 |
| Alt | listing 图库没有卖家可填的 alt 字段，不写 Alt 行 |

#### 与 A+ 的写法差异

1. **每张独立成立。** 买家跳着看，不能靠上一张承接；不用问句/转折句衔接，不做连图。
2. **字更少。** 大标题 ≤2 行、≤45 字符；正文 ≤3 行。手机缩略图约 360px 宽，最小字号按设计稿 ≥28px。
3. **核心数字前置。** 每份剂量/规格在副图 1～2 张就出现，并始终带对象和份量（`700mg per 2-capsule serving`）。
4. **叙事顺序（对标库归纳，随产品陌生程度调整）：** 身份＋一个数字 → 多利益 → 成分/来源 → 怎么用/温和 → 对照表 → 数字解释 → 场景 → 标签（查证放最后）。
5. **对照表**：对照列按属性限定（如 “Without These Standards”），不写泛指 “Other brands / Other {成分}”；红叉改灰色短横，对照列文字灰色细字；每一行都要有事实编号。
6. **标签图**：Supplement Facts / 成分表逐字与实物一致，学名种加词小写，Other Ingredients 不重复；徽章逐个核对依据。
7. **食物/原料图**：如果标签写明来源（如 Punica granatum Peel Extract），可以直接指向来源；否则只作隐喻（同基线规则 6）。
8. **FDA 声明按图放**：副图之间不共享，哪张有带 `*` 的句子，哪张底边就要放。首张副图若不想放小字，改用无功效的规格句。
9. **主图不写。** 用户没给主图文件时，在 plan 里确认“主图为纯白底产品图，无文案”。

#### 检查

- `scan_copy.py … --listing`：残留中文占位字符 → FLAG；含“标题”的文字位超过 45 字符或 2 行 → WARN。
- 顺序建议写进 plan 的确认项（例如标签图与场景图互换），由用户拍板；文案表的分组名写清“副图8·场景（原副图9）”，避免设计对错文件。
