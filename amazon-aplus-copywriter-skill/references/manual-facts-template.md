# 手动产品事实填空模板

发给用户填写（中英文皆可；英文原文优先）。带 ★ 为必填。

```
★ 品牌名（与 listing 品牌字段一致）：
★ 产品名称 / 标题：
★ 站点：（默认 Amazon US）
★ 品类：（如 膳食补充剂 / 护肤 / 家居 / 电子）
★ 五点描述（原文粘贴）：
  1.
  2.
  3.
  4.
  5.
★ 核心规格：每份含量＋每份单位（如 700mg / 2 capsules）、总数量、份数、剂型
  标签信息（Supplement Facts / 成分表原文，或上传标签图）：
  使用方法（listing 原文）：
  适用人群：
  可用的认证/徽章及证据（如 cGMP、Non-GMO、Gluten-Free、Vegan、第三方检测）：
  原产地的准确说法：
  品牌 slogan / 创立故事（如有）：
  是否开通 Subscribe & Save：
  不能出现的说法（公司或平台要求）：
  同品牌其他款（避免素材混用）：
```

收到后：逐项编号为 F01…，出处写"用户提供（日期）"；缺失的 ★ 项列入 plan 待确认。
