## 如何理解本库

**观察**指在当时公开页面、源图或浏览器中实际看到的内容；**分析**是对表达作用和消费者决策的推断；**原创模板**是可填空的重新组织，不是原站文案。功效、检测、品质、结果图等如无独立核验，均视为品牌主张。

45个官网HTML页面已登记，其中空白、重复入口与范围外页面只作索引，不冒充有效产品分析。49个网站折叠项含46FAQ和3组参考资料，答案内容已读取；19个成分内容面板与5个检测标签另列。浏览器实际点击、手机布局及截图状态以覆盖清单和验收记录为准。未实测登录、结账、订阅扣款、奖励注册、客服或全部轮播交互；未独立核验临床效果及逐批检测文件。官网产品16个FAQ及Amazon的5个A+问答已全部展开核验。弹窗配图保留完整截图，独立原图URL未取得；Amazon手机专用版本未实测。所有剩余边界都保留，不把“内容已读”写成“全部交互已实测”。
