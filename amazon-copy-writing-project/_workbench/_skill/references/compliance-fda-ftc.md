# 补充剂文案：证据、主张与限定说明

> 官方规则核验：2026-09-05，美国市场。法律要求、平台要求和本 skill 的编辑策略分别标注。
> 先判断整张图承诺了什么，再判断资料能否支持；不是把强词替换成 supports 就通过。

## 1. 判断依据与适用边界

- **FDA 标签与 labeling 规则**：膳食补充剂的结构/功能等 403(r)(6) 主张需真实、有依据，并满足相应免责声明和通知要求；不能明示或暗示诊断、治疗、治愈、缓解或预防疾病。结构/功能主张不代表 FDA 批准。疾病风险降低类健康声明有另一套授权规则，本 skill 不自行创造此类声明。[FDA：Label Claims](https://www.fda.gov/food/nutrition-food-labeling-and-critical-foods/label-claims-conventional-foods-and-dietary-supplements)、[FDA：403(r)(6) 通知与条件](https://www.fda.gov/food/information-industry-dietary-supplements/notifications-structurefunction-and-related-claims-dietary-supplement-labeling)
- **FTC 广告要求**：明示与合理暗示的客观主张都需相称的支持；功效与安全通常需要可靠科学依据。同时看标题、画面、图标、前后对比和脚注形成的整体印象。免责声明、模糊措辞或问句不能消除相反的明确承诺。[FTC：Health Products Compliance Guidance，§III.A–B](https://www.ftc.gov/business-guidance/resources/health-products-compliance-guidance)
- **平台要求**：Amazon 可以比法律更严格；A+ 禁用的排名、竞品比较等不因证据存在而放行。主图、商品标题和 A+ 分别按[平台与版式规则](amazon-layout.md)执行。竞品在售或使用过某句不构成许可。
- **本 skill 的默认策略**：材料足够的部分直接写；无法支持的主张删除或换成另一项已确认事实。仅对阻碍本次交付的缺口集中提问，不要求所有任务先经过法务、不以“可能需要审查”阻塞普通事实文案。

## 2. 将每项主张连到正确材料

| 主张 | 检查重点 | 材料缺失或不匹配时 |
|---|---|---|
| 粒数、每份含量、用法、包装 | 使用当前 SKU 标签；区分每粒与每份、净重与有效成分量。标签冲突不能自行选值 | 先完成不受影响的图；剂量或天数暂不进入成稿 |
| 风味、溶解、口感、便携 | 可依据本品已确认描述或测试；评论只提供买家语言和顾虑 | 不把“大家喜欢竞品口味”改成本品好喝，也不把粉剂自动称为易溶 |
| supports / helps maintain / appearance 等功能或外观利益 | 表达仍是主张，需匹配实际配方、剂量、目标人群和所说结果的依据 | 删除利益承诺，改写已确认的成分、规格、用法或场景事实 |
| 临床、百分比、吸收比较、见效时间 | 明确成品还是原料研究；核对设计、样本、剂量、人群、比较对象、终点和期限，区分组间差异与组内变化 | 不写“clinically studied”掩饰研究不适用；不用“调研显示”替代缺失出处，也不把数字换成无依据定性效果 |
| 认证、检测、质量数量 | 核对机构、范围、有效性与适用 SKU；区分公司年度总测试数、产品批次检测和产品认证 | 缺认证则不用名称、徽章或 certified；有检测也不推断无副作用、人人安全或运动员绝对安全 |
| 排名、推荐、用户百分比 | 除真实来源外还要核对范围、时期、方法及平台位置许可 | 无来源就删；A+ 不写 best-selling/top-rated；消费者自报告不能单独证明健康功效 |

研究材料的判断依据：[FTC 健康产品指南，§III.B](https://www.ftc.gov/business-guidance/resources/health-products-compliance-guidance)。不凭论文标题、摘要、原料名称相同或研究脚注就确认本品效果；不把自家认证从一个 SKU 扩展到全线。

## 3. 常见问题：更改承诺，不做机械替词

| 输入或草稿 | 正确处理 |
|---|---|
| treats insomnia / cures acne / prevents disease | 删除疾病语境；若有独立、充分支持的正常功能或外观主张，可重新组织，否则只写产品事实 |
| clinically proven → clinically studied | 先检查研究是否对应本品和承诺；仅改动一词不能解决问题 |
| detox / rapid fat burn → supports metabolism | 新表达仍需自己的依据，不能把一项无依据功效替换成另一项 |
| safe for everyone → third-party tested | 删除绝对安全承诺；仅在确有本品检测资料时另写检测事实，画面也不能继续暗示人人安全 |
| hair growth / anti-aging → appearance / healthy aging | 根据实际含义、图像和材料判断，美容或温和词不是豁免；不能假设图片区审核更宽 |
| #1 + 脚注 / before-and-after + results may vary | 脚注不是使用许可；要同时满足证据、整体印象、典型结果披露及具体平台要求 |
| 竞品徽章、口号、名人、消费者故事 | 仅观察表达方式；不迁移商标、专属口号、代言或他人功效到本品 |

**视觉同步**：删去“更快长发”时也删去暗示生发的前后照片、箭头或增密标尺；删除排名文字时也删去 #1 奖章。机制图不能制造未经支持的效果、速度或确定性。前后对比默认不主动选用；用户指定时核对素材真实性、相关证据与平台许可，条件不足就改成不承诺结果的事实图，不让整包停在等待状态。

## 4. 免责声明：按用途说明，不混为一项通用法定要求

**Labeling 的法定要求**：适用的补充剂结构/功能声明应按 FDA 要求配套免责声明；相关企业还承担首次上市声明后 30 天内通知等责任。通知不是批准，本 skill 生成文案也不代表完成通知。[FDA 说明](https://www.fda.gov/food/information-industry-dietary-supplements/notifications-structurefunction-and-related-claims-dietary-supplement-labeling)

**广告的区别**：FTC 明确，DSHEA 这段 labeling 免责声明并非所有其他形式广告的统一强制要求，也无法挽救误导广告。线上材料可能同时涉及 labeling，要按实际用途及平台要求判断，不能简单把全部网页内容划为纯广告。[FTC 指南，§III.C.3](https://www.ftc.gov/business-guidance/resources/health-products-compliance-guidance)

**本 skill 的图片默认策略**：对采用有依据结构/功能主张的副图或 A+，默认在同图预留清晰可读的声明区，并在“依据与限定说明”标出全文与对应符号。这是保守的交付策略，不声称每张商品图都依法必须加声明。纯包装、用法或成分事实图不自动添加；用户提供了适用格式时按其执行。

多项声明常用全文（单项时第一句用 `This statement has`）：

> These statements have not been evaluated by the Food and Drug Administration.
> This product is not intended to diagnose, treat, cure, or prevent any disease.

研究和条件脚注另列；重要限定要靠近相关主张并在移动端可读，不能只留在文案包末尾。“结果因人而异”不能代替对真实典型结果的披露。不额外创造第 6 条 bullet 来塞声明。

## 5. 交付时做一次对应检查

1. 对每张图的文字和视觉检查明示/暗示主张，关联所用材料。事实、合理场景和买家假设分清楚。
2. 仅登记实际处理过的问题：原表述 → 删除或有据改写 → 原因/所缺资料；不写“已保证合规”。
3. 最终成稿不混入待核实认证、占位研究数据或竞争品牌的证据；关键缺口另列，能完成的部分直接交付。
4. 声明正文与内部依据记录分层；明确哪些限定须上图，避免设计师把它们当作内部备注而省去。

品牌语气只改变节奏和解释深度，四套 voice 使用同一证据门槛。对复杂研究的解释确需专业判断时，准确指出这一项待确认内容，不把每次文案生成改成全面法律审核流程。
