# 剂型事实清单

写简报和排图任务前读取。用于确认**本次剂型有哪些可用事实、怎么说清口径、哪些结论不能从剂型本身推出**。

> 剂型是事实，不是功效证据。软胶囊、软糖、果冻、粉剂等形态可以如实描述，但"更好吸收""对肠胃更温和""起效更快""口感好"都需要本品自己的材料；同类剂型的原料研究同样不能直接推成成品结论。剂型用词必须准确：softgel ≠ capsule ≠ tablet ≠ gummy ≠ jelly，写错会同时带来退货和合规风险。

## 0. 所有剂型共用的口径与禁止项

**口径**

- 区分**每份**与**每粒/每粒软糖/每袋**：写每份剂量时明确 per serving，避免与 per softgel、per capsule 混淆。
- 区分**净含量/化合物总重**与**有效成分含量**；商品标题也要写明计量对象。
- 份数 = 总数量 ÷ 每份数量；天数按标签实际用法计算，不自行调整用法去凑一个整齐的天数。
- 数量与用法以当前 SKU 标签为准；标签内部冲突不能自己选值，先完成不受影响的图。

**容器**

未注明外容器时不写 bottle、box、tub、jar，用总粒数、总袋数或份数表达。设计建议引用实际包装素材，不凭剂型创造容器形象。

**感官与体感**（没有本品材料时一律不写）

easy to swallow、small and easy to take、gentle on the stomach、no aftertaste、tastes great、dissolves fast、no chalky texture、won't upset your stomach。

**用法时间**

标签没有指定时，不写 before breakfast、空腹、睡前、训练前后等新增服用指令；早餐、通勤等场景只能作为画面背景，且不能只在内部备注里解释消费者可能误读的标题。

**剂量展示**

剂量图先给出实际剂量（成分、数量、口径），不要先自评 clearly stated、transparent。每天粒数的额外换算（如每周粒数）只在买家确实会问时使用。

## 1. 软胶囊 Softgel

| 项 | 内容 |
|---|---|
| 可用事实 | 每粒含量、每份粒数、总粒数、供应天数、标签用法、标签列明的载体油脂、已确认的检测或认证 |
| 可写角度 | 每天几粒即可完成；油脂载体让成分以溶解状态存在（限标签已列明载体时）；随餐服用的用法事实；总量与天数 |
| 不得推断 | 更易吸收、生物利用度更高、吸收率优于胶囊或片剂、对肠胃更温和、降低成分降解、无鱼腥味或无打嗝感——除非本品有对应材料并写清适用条件与人群 |
| 视觉注意 | 展示真实软胶囊形状与颜色，不放大成片剂样式，不加光泽特效暗示"吸收更好"；剂量口径与标签一致 |
| 口径提醒 | 软胶囊常按"每粒含 X mg"标注，但**每份**可能是 2 粒；标题与剂量图都不能把每粒含量说成每份含量 |

软胶囊形态本身是可以说的差异化事实（外观、剂型、每日粒数、是否含油脂载体）。它**不能**独自推出吸收或肠胃友好结论——这类主张属于功效层面，按[事实与声明核对](compliance-fda-ftc.md)处理。

## 2. 硬胶囊 Capsule

| 项 | 内容 |
|---|---|
| 可用事实 | 每粒含量、每份粒数、总粒数、天数、标签用法、胶囊来源（如植物胶囊，仅限标签确认）、已确认检测 |
| 可写角度 | 每日粒数与剂量透明；份数供应；随餐或标签指定的用法 |
| 不得推断 | 易吞咽、无味、素食友好（除非标签确认为植物胶囊且可核）、吸收速度、对胃温和 |
| 视觉注意 | 不按想象缩小胶囊尺寸；不添加吞咽演示或"一口水搞定"的画面暗示 |
| 口径提醒 | 与软胶囊一样按每粒/每份分层标注，避免 gummy 等剂型错配词进入文案或后台词 |

## 3. 片剂 Tablet

| 项 | 内容 |
|---|---|
| 可用事实 | 每片含量、每份片数、总片数、天数、标签用法、可否分片（仅限标签标示刻痕或明确允许时）、已确认检测 |
| 可写角度 | 每日片数与份量；可否掰开服用的标签事实；供应周期 |
| 不得推断 | 易吞服、无苦味、不伤胃、崩解更快；未标示刻痕时不写 split in half |
| 视觉注意 | 分片画面只在标签允许时使用；不展示"半片"暗示剂量可自由调整 |
| 口径提醒 | 咀嚼片、泡腾片、含片是不同剂型，用法与字数表达不能互换 |

## 4. 软糖 Gummy

| 项 | 内容 |
|---|---|
| 可用事实 | 每粒软糖含量、每份粒数、总粒数、天数、标签确认的风味与甜味来源、标签用法、已确认检测 |
| 可写角度 | 每天几粒；标签确认的口味名称；作为日常习惯的使用场景 |
| 不得推断 | 好吃、像糖果、孩子爱吃、无糖（除非标签确认）、不粘牙、比胶囊更好坚持（除非本品有调研材料） |
| 视觉注意 | 风味可以用颜色表达，但展示真实水果时不把风味说成真实原料来源；不把软糖画成糖果包装形态 |
| 口径提醒 | 软糖常按 2 粒/份标注；糖醇含量与"无糖"是标签事实，不可从剂型推定 |

## 5. 果冻 / 咀嚼凝胶 Jelly

| 项 | 内容 |
|---|---|
| 可用事实 | 每袋含量、每份袋数、总袋数、天数、标签确认风味、食用方式（直接食用/冷藏后食用等标签说明）、已确认检测 |
| 可写角度 | 一次一袋或一次几条的用法事实；携带与即时食用场景；标签风味；份量与供应周期 |
| 不得推断 | 好吃、Q 弹口感、饱腹感、代餐效果、加速代谢、帮助控制体重 |
| 视觉注意 | 不出现体重秤、腰围对比、身体轮廓变化、体型前后对比；不出现指示性箭头或标尺 |
| 口径提醒 | 包装为条/袋时按条数或袋数表达总量，不默认写成 bottle 或 box |

**体重管理语境的红线**：若产品属于"切割/体重管理"概念，但既没有对应的平台认证，也没有本品自身证据，则**不写 weight loss、fat burning、fat burner、cutting、slimming、appetite suppressant、belly fat** 等直接减重表达，也不使用"帮你瘦下来""告别赘肉"一类中文卖点的英文直译。可写的是已确认的配方事实、每份剂量、标签用法、风味与份量。产品名或类目名中包含体重管理词汇，不构成本品可以这样宣称的许可。

## 6. 条装 / 份装粉剂 Stick pack & sachet

| 项 | 内容 |
|---|---|
| 可用事实 | 每袋克数与有效成分、每份袋数、总袋数、天数、标签冲调方法（水量与水温）、标签确认风味、已确认检测 |
| 可写角度 | 一袋就是一份的直接说明；通勤包、办公桌、行李箱的携带场景；按标签准备 |
| 不得推断 | 秒溶、无结块、好喝、不需要搅拌、无砂感、可替代其他补充剂或正餐 |
| 视觉注意 | 不暗示杯子、摇摇杯或水瓶随产品赠送；水量按标签标注 |
| 口径提醒 | 独立份装不必补写外容器；用总袋数与天数表达总量 |

## 7. 散装粉剂 Powder（罐装等）

| 项 | 内容 |
|---|---|
| 可用事实 | 每份克数（或每勺克数）、罐内总份数、标签量勺规格、标签冲调方法与水量、已确认风味、已确认检测 |
| 可写角度 | 每天一勺的准备动作；每份与整罐份数；按标签的冲调步骤 |
| 不得推断 | 秒溶、顺滑、无后味、真实水果来源、自动替代其他补充剂 |
| 视觉注意 | 展示实际容器形态与量勺；量勺随附情况要有材料依据，不凭"一份一勺"推定量勺内附 |
| 口径提醒 | 标签未注明每日勺数时只写每份克数与总份数，不写"每天一勺" |

## 8. 液体 / 滴剂 / 喷雾

| 项 | 内容 |
|---|---|
| 可用事实 | 每份体积或滴数、每瓶总量与总份数、天数、标签使用方式（直接滴入口中/加入水或饮品）、已确认风味、已确认检测 |
| 可写角度 | 剂量口径与用法；随行携带；按标签加入饮品 |
| 不得推断 | 吸收更快、入口即见效、无味、不刺激、无需计量 |
| 视觉注意 | 滴管或喷头按实际包装展示；不展示超过标签剂量的画面 |
| 口径提醒 | 液体的毫升数与有效成分含量分开写，不与重量单位混用 |

## 9. 写完之后回看三点

1. 剂型词是否与实际销售形态一致，且全篇统一？
2. 每一句剂型相关的描述，是**形态事实**还是**功效结论**？功效结论有本品材料吗？
3. 每份/每粒/每袋的口径，是否在标题、支撑句、剂量图和商品标题之间保持一致？
