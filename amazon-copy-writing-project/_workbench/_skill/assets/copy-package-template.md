# 文案包交付模板

使用说明：只保留用户请求的部分，复制并替换占位；不要把本模板的说明或空模块交付给用户。英文是消费者可见文案，中文是结构/设计/内部说明。先给成稿，再给简短内部依据；用户明确要求先看策略时可调整顺序。

图片标题默认一个推荐版与一个不同角度的备选；商品标题保留一个主推与两个备选。无图片任务时不额外生成图片方案。收到带 `*##*` 标记或含并列槽位的设计稿时，先交槽位映射块，再交逐槽成稿与对应图卡。
