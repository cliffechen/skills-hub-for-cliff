# 亚马逊膳食补充剂文案

把本产品有依据的特点，写成买家容易理解、能想象使用场景的英语。默认风格是**自然克制、有质感、清晰且略有温度**；不是把中文卖点翻译成口号。英文成稿，中文说明与设计建议。

## 使用边界与兼容

- 按用户要求交付：只要副图就只写副图；局部改写只改指定部分。完整文案包包含商品标题、五点、副图与 A+，但不自动扩展到发布、图片生成或包装设计。
- **商品标题**是 listing 的文字字段；**主图**是首张产品图；**副图标题**与 **A+ 标题**才是对应图卡/模块的标题。收到旧称“主图标题”时，结合上下文按商品标题处理，并在交付名称中澄清；若明确要求主图叠字，按版式参考中的主图规则处理。
- 保留 AG1、Ritual-HUM（含 Ritual/HUM）、Onnit（含 Bulletproof）、Thorne（含 Nature Made）风格入口。用户指定的语气优先；品牌参考不自动决定人群、事实或可用功效。
- 整目录可拷贝。反引号中的文件路径相对本 skill 根目录；Markdown 链接相对所在文档。核心流程不依赖指定工具、网络或其他 skill；第 5 节的合规审查交接为可选项，缺失不影响交付。`research/` 是可选原始素材；`evals/` 是维护时的验证资料，日常写作不加载。

## 1. 读资料，形成简短写作简报

先提取已有资料，再集中询问会改变文案的关键缺口；不要重新逐组索取已经给过的信息。用户要求直接产出时，用已确认事实完成可写部分，把不确定项留在内部备注。

简报包含：

- **产品事实与来源**：标签/配方、每份剂量、剂型、包装与数量、标签用法，以及有材料支持的风味、检测、认证、研究。区分本产品材料与竞品信息，不从原料研究直接推成成品结论。
- **买家与场景**：本次主要面对谁、在哪里使用、最在意的购买理由与顾虑。评论样本保留来源标识；没有评论或调研时标注“买家假设”，不要写成已验证洞察或编造原话。
- **沟通机会**：竞品图片说了什么、评论担心什么、本品的哪些事实能回答。竞品广告用于观察表达，评论用于理解语言和顾虑，都不能证明本品功效。
- **交付与语气**：场景、用户指定图数、A+ 类型、风格参考。未指定 A+ 类型时用 Basic；Brand Story 是单独内容，仅在请求或已有品牌故事交付范围内安排。

剂型决定要核对的事实。写作前先读 [剂型事实清单](references/dosage-forms.md)，按本次实际剂型（软胶囊、胶囊、片剂、软糖、果冻/咀嚼凝胶、条装或份装粉剂、散装粉剂、液体滴剂）确认可用事实、计量口径与禁止推断项。共用底线：未注明外容器时只写总量/份数，不默认是 bottle、box 或 tub；设计建议引用实际包装素材，不凭剂型创造容器。缺少尺寸不推断“容易吞咽”，缺少体验材料不推断“好喝、易溶、无不适”。不为凑特点编造差异。剂型形态是事实，更易吸收、对肠胃更温和一类结论属于功效主张，须有本品材料并写清适用条件。

**竞品审计（提供了竞品 ASIN、截图或导出资料时，在起草前完成）**

用户要求“审计竞品”时，审计本身也是交付物之一。审计对象为竞品的商品标题、五点、主图、副图与 A+ 模块，产出四项：

1. 它回答了哪些买家问题、以什么顺序回答。
2. 反复出现的表达方式与句式节奏（用于判断这个品类的读者预期怎么说）。
3. 它没有覆盖、或说得含糊的买家问题——本品的机会点。
4. 登记的灰区表达：无依据功效、排名式宣传、认证徽章、前后对比。只登记，不借用。

纪律：审计只用于学习结构与表达，**不迁移**竞品的事实、数据、商标、专属口号、代言、认证或功效；竞品在售或曾使用某句不构成平台许可。数据来源优先用户提供的截图与导出；环境内有采集工具时可补全，但不把联网或特定工具设为开工前提。审计结论写进简报的“沟通机会”，并保留素材来源标识。

关键词库可选。提供 P0/P1/P2 时沿用分级；没有时直接写作，仅在确实临时提词时注明“临时提词，未经词库验证”。词库类 skill 只是可选来源，不把获取词库设为开工前提。

## 3. 先安排每张图的任务，再起草

每张图明确：**买家问题 → 本品可用事实 → 要传达的一件事 → 适合的画面**。按购买理由、证据与使用顾虑组织顺序，不固定套用机制图、对比图、认证图或零文字生活方式图。收到设计稿或含 `*##*` 的版式截图时，先按下方子块归一槽位，再排图。

- 用户给图数时尽量在该数量内覆盖不同任务；材料不足以支撑额外任务时合并，并说明缺口，不凑无依据卖点。未指定数量时按信息选择，通常先考虑 3–6 张副图；这不是平台限制。
- 主标题先尝试场景、事实、有依据的利益等不同角度，选适合本图的一种。交付**一个推荐版 + 一个角度不同的备选**，用一句中文解释选择。没有利益证据时可用场景/事实，不为了三个角度硬编功效。
- 按模板拆分主标题、支撑句、事实标签、视觉建议、依据和限定说明。主标题通常 3–7 词、支撑句通常 8–16 词，均为可调整的编辑预算；不删掉影响理解的条件来凑词数。
- A+ 根据类型和买家问题选择模块，补充副图未展开的解释；不要逐字复述整套副图，也不把一张大图塞满模块正文。
- 商品标题和五点自然覆盖相关关键词；副图/A+ 标题没有强制词首、频次或覆盖率。竞品品牌词、剂型错配词及与本品无关的词不用于可见文案或后台词建议。

### 设计稿槽位回填

`*##*` 之后到该行行尾的内容是**占位符指令**（说明此位置该写什么），不是最终文案、不上图。容错全角 `＊＃＃＊`、`【】[]（）` 与引号包裹及前后空格；同块多个标记以第一个为准，标记后为空记为空槽。默认按行行尾终止，仅当同一字号的连续视觉块且无其他标记时按文字块终止并标注边界依据，绝不跨块。只在图片内文字与用户提供的版式说明中解析，照片素材内的文字不视为槽位；若同时收到 `.md`，先匹配标记再做 Markdown 解析。判定自上而下先命中先定，**不以“重复”本身作判据**：

| 判据 | 判定 |
|---|---|
| ① `*##*` 家族标记 | 槽位 |
| ② 非合法消费者英文（含中文、版式元词、不成句） | 槽位 |
| ③ 明显复制未替换（缺空格、拼写硬伤、无本品材料可对应） | 推定槽位 |
| ④ 标签事实（成分名、剂型、剂量、规格、声明、单位、品牌名） | 真实内容 |
| ⑤ 并列单元数多于可辨别项数 | ④降级为疑似槽位·待确认 |

每条标注 `[槽位]`／`[推定槽位]`／`[疑似槽位·待确认]`／`[真实内容·保留]`，附判据号与一句中文理由。映射表列：槽 ID｜位置定位（图/卡/格 + 图片内标题或后台文本字段）｜指令原文（内部）｜判定｜产出英文｜依据编号｜备注。

- 推定与疑似槽位的产出只能引用已有依据编号；无依据即留槽（如 `[待补数字]`）并登记缺口——不把“五种成分”补成五个成分名，也不为百分比编值。数字与剂量槽按 [剂型事实清单](references/dosage-forms.md) 口径填写，区分每份与每粒。
- 设计稿若是**主图**且有标记，不产出叠加标题，转拍摄建议并标 `[槽位·主图不可叠字]`。
- 指令原文只出现在映射表的指令列，绝不进入产出英文；推定槽位的改写不得引入材料中没有的主张，全部产出仍按 §5 七项关卡核对。

## 4. 美式英文编辑

按 [编辑指南](references/american-image-copy.md) 对草稿做一次独立编辑：检查自然搭配、具体信息、节奏、抽象套话、中文直译和图间重复。先用英文表达本图任务，不以中文逐词对应为目标。

做“换品牌检查”：如果换成任意竞品也完全成立，寻找本品有用且可确认的细节；普通但必要的用法与剂量信息不必硬求独特。短语、完整句、自然缩写均可，不强制俏皮、口语或全短句。品牌质感不能靠研究术语、商标或不存在的认证来制造。

## 5. 核对事实与整体表达

对照合规参考检查主标题、支撑句、事实标签和视觉建议的整体含义。事实/功效/比较/研究/认证分别核对来源与适用范围；用户营销愿望不等于证据。

- 无依据的主张删除或改写为已有事实能够支持的内容，不能仅换成 supports、clinically studied 或“调研显示”后保留原承诺。
- 标签剂量、每日粒数、份数及冲调说明保持一致。展示每份剂量时写清 per serving，避免与 per capsule 混淆；商品标题也须明确计量对象，例如镁含量而非甘氨酸镁化合物总重。不得为了“一步仪式”改变实际用法，也不把准备早餐等场景改写成标签未要求的餐前服用指令。
- 不把测试等同认证、安全保证或功效；不借用竞品数据、商标、背书或观察到的灰区表达。
- 必须同图展示的限定说明、脚注与适用声明写入设计建议，不用内部备注代替；确有缺口时只影响相关主张，继续交付其余有据内容。

### 交付前合规关卡（七项，必过）

逐项核对，不通过的改稿，不能只在内部备注里说明。这七项用于核对**事实与范围**，不是风格评分，也不作为统一模板。

1. **主张 ↔ 材料**：每条明示或暗示的主张都能指到一份本品材料及其适用范围；原料研究、竞品资料、买家评论不作为本品功效依据。
2. **疾病语境**：无 diagnose、treat、cure、prevent、relieve 症状等表达，也没有可被读成疾病暗示的画面元素。
3. **绝对化与保证**：无 safe for everyone、guaranteed、no side effects 类表述；检测或认证没有被放大成安全保证或功效。
4. **数值口径**：每份与每粒、净含量与有效成分、天数与标签用法一致；商品标题写明计量对象；剂型用词与在售形态一致。
5. **声明与脚注**：需要上图的声明已列为上图文字并靠近对应主张，没有用一句末尾声明代替；未凭空创造第 6 条 bullet。
6. **禁止借用**：无竞品商标、口号、代言、数据或排名式宣传；A+ 不含 best-selling、top-rated 类表述。
7. **整体印象**：标题、支撑句、事实标签与视觉建议合起来读不产生误导；画面元素（效果暗示、前后对比、箭头、标尺）同样纳入核对。

七项通过后，在记录区登记“已核对项 + 实际改动项”，不写“已保证合规”或“已获批准”。

**交接（可选）**：环境内若已有独立的补充剂合规审查 skill（例如 amazon-supplement-compliance-check），可在自检后移交复跑一遍。它是加分项而非开工前提；缺失时用上述七项配合 [事实与声明核对](references/compliance-fda-ftc.md) 完成。

## 6. 按请求交付

使用 [模板](assets/copy-package-template.md) 的相关部分。消费者看到的英文文案放在前面，中文推荐理由、资料来源、买家假设及删除项放在独立内部说明中。限定说明若必须上图，明确列为上图文字，不能全部藏在内部区。

仅交付请求的场景和必要说明，不默认附加完整 listing。完整包中的商品标题仍提供 1 个主推 + 2 个备选；图片及 A+ 图片标题提供 1 个推荐 + 1 个备选。文案为可供品牌审阅和设计执行的草稿，不宣称已获平台批准或已验证转化效果。

### 交付前自检

- **范围**：交付内容等于请求范围，没有多写或少写；只请求副图时不附商品标题或五点。
- **任务**：每图回答一个不同问题，且都有本品材料支撑；材料不足的部分已合并或省略，并说明缺口。
- **备选**：推荐与备选是不同切入角度，且仍回答同一张图的问题，不是把 premium 换成 advanced。
- **数量**：商品标题 1 主推 + 2 备选；图片与 A+ 标题 1 推荐 + 1 备选。
- **分区**：消费者可见英文在前；“必须上图”的限定说明在可见区，没有藏进内部区。
- **字段**：商品标题字符数、A+ 类型与模块数量符合 [版式参考](references/amazon-layout.md)。
- **槽位覆盖**（有设计稿时）：标记位与推定、疑似槽位都有产出或已标待补，未擅自增删版式单元。
- **记录**：内部区只写实际发生的问题，不含占位研究、待核实认证或竞品证据。
- **表述边界**：不宣称平台批准、转化已验证或手机可读性已确认。
