# amazon-copy-writing-project · 亚马逊产品文案工作台

可复用的本地项目：为亚马逊产品的设计稿（详情页 / A+ / 轮播图）撰写四风格合规文案，并在可视化工作台里完成「看图 → 找槽 → 改稿 → 合规检查 → 导出」。

- **纯离线运行**：Python 3 标准库 + 原生 HTML/CSS/JS，无 npm、无构建、无 CDN；服务只绑 127.0.0.1。
- **当前内置内容**：一个藻钙类产品的完整文案与坐标，作为结构与语气示例；其历史资料在 `_archive\`。

## 目录结构

```
amazon-copy-writing-project\
├── *.png / *.jpg …        设计稿图片（服务根目录，文件名随意，支持中文与空格）
├── 设计稿放这里-换新产品请删除旧设计稿.txt   ← 设计稿 / 资料的存放指引
├── 资料\                  产品事实材料（每层都有指引 txt）
│   ├── 产品规格与成分表\     SF 面板、装量、剂型、%DV、成分清单
│   ├── 可用主张的材料依据\    每条主张对应的检测报告 / 原料商文件
│   └── 禁用与白名单口径\     禁用词表与可用主张口径（更新后同步 copy.json 的 meta.banned）
├── _workbench\            工作台（copy.json 是唯一数据源）
│   ├── copy.json          文案数据：meta / styles / modules(slots + 坐标)
│   ├── server.py          本地服务（Python 3 标准库）
│   ├── index.html / app.js / style.css
│   ├── 启动工作台.bat      Windows 双击启动（.sh 为 macOS / Linux）
│   ├── README.md          使用说明（快捷键 / 常见问题）
│   ├── _skill\            写作方法论（合规 / 剂型 / 四风格声线等参考文档）
│   ├── .backup\           copy.json 历史快照（自动生成，保留最近 30 份）
│   └── 导出\              导出的 Markdown（自动生成）
└── _archive\              上一代产品的历史资料（可整目录删除）
```

## 换新产品（标准流程）

1. **清旧**：删除根目录里旧产品的设计稿图片；
2. **进新**：新设计稿放进根目录，产品资料放进 `资料\`（**没有材料不写文案**——每条主张都要能指到一份材料）；
3. **写**：在 ZCode 项目聊天框说「**为项目文件夹下产品设计稿写文案**」——已安装的 `amazon-copy-writing` skill 会按 `_skill\` 方法论看图、写四风格文案、重写 `_workbench\copy.json`（含槽位坐标估计值）；
4. **审**：双击 `_workbench\启动工作台.bat` → 「标定」模式把高亮框对准文案位置 → 保存 → 「合规检查」→ 「导出 ▾」按风格导出 Markdown。

不接 LLM 也可以：人工照 `_skill\` 的规则直接在工作台页内改写（点正文即可编辑，`Ctrl+S` 保存）。

## 启动

### Windows

双击 **`_workbench\启动工作台.bat`**。启动后控制台打印端口（从 8787 起自动寻找），浏览器自动打开 `http://127.0.0.1:<端口>/_workbench/`；**关闭窗口即停止服务**。

### macOS / Linux

```bash
cd _workbench && ./启动工作台.sh
```

> ⚠️ 不要直接双击 `index.html`——`file://` 下浏览器不允许读取 `copy.json`。

## 快捷键

| 键 | 行为 |
|---|---|
| `←` / `→` | 上一个 / 下一个模块 |
| `↑` / `↓` | 上一个 / 下一个槽位 |
| `1` `2` `3` `4` | 切换风格 A / B / C / D |
| `Tab` | 工作台 / 四风格对比视图切换 |
| `Ctrl` + `S` | 保存（写回 copy.json，自动备份） |
| `Ctrl` + `Enter` | 编辑态提交 |
| `Esc` | 退出标定 / 取消编辑 / 关闭浮层 |
| `?` | 快捷键与使用说明 |

输入框聚焦时，除 `Ctrl+S` 与 `Esc` 外全部禁用。

**主题**：顶栏 `☀️ / 🌙` 按钮切换日间 / 夜间模式（默认夜间，选择记忆在浏览器）。点击图上高亮框或槽位正文时，右侧对应卡片会以高亮色整卡显示。

## 数据与备份

- **`copy.json`** 是唯一数据源，页面只是它的读写视图；换产品时由 skill 或人工整体重写。
- 每次保存先备份到 `.backup\copy-YYYYMMDD-HHMMSS.json`，只保留最近 30 份；回滚 = 停服务 → 用快照覆盖 `copy.json` → 重启。
- 「完成」勾选按产品隔离存在浏览器 localStorage（`copywb.done.*`），**不写入** copy.json，换产品自动重新计数。
- 导出的 Markdown 在 `导出\`，文件名含风格与时间戳。

## 常见问题

**双击 .bat 闪退 / 提示找不到 python？** 本机需装 Python 3（安装时勾选 Add Python to PATH）。在命令行手动执行 `python server.py` 可看完整报错。

**端口被占？** 自动从 8787 找到 8806，控制台打印实际端口；`netstat -ano | findstr 8787` 可查占用。

**图片不显示？** 确认图片在 `_workbench` 的**上一级**目录（服务根目录），且通过 `http://127.0.0.1:<端口>/_workbench/` 访问而非 `file://`；中文文件名与空格括号均支持。

**中文乱码？** 页面与数据均为 UTF-8；控制台乱码不影响页面。

**合规检查报出 note 里的词是误报吗？** 不是误报范围问题——检查只扫描产出英文 / 备选 / 名称 / 剂量 / 说明 / 表格行，不扫 note、insp、保留原文与 DSHEA 声明（这些引用被删原文属正常）。若真报出了，说明代码被改错。
