# 选品报告 HTML 视觉规范

## 1. 参考图片的共同版式

- 基准宽度为 1080px，采用纵向长页或长图阅读方式。
- 页面外层使用深海军蓝作为背景与模块间分隔带，内容全部放在白色圆角卡片内。
- 每个大模块独占一个白色卡片，卡片之间保留 12-20px 深色间隔。
- 页面以“结论卡 → 数据图 → 明细表 → 行动方案”的顺序向下阅读。
- 商品明细和证据表允许信息密集；结论区必须留白充足、字号更大。

## 2. 色彩系统

| 角色 | 建议颜色 | 用途 |
| --- | --- | --- |
| 页面底色 | `#0F172A` / `#101020` | 长页背景、模块分隔 |
| 主蓝色 | `#6378E5` / `#6070E0` | 表头、方案卡标题、主强调 |
| 深表头 | `#26384A` / `#203040` | 审计表、机会矩阵、明细表 |
| 浅紫底 | `#EEF0FF` | 结论、限制、原始判断 |
| 浅绿色 | `#E4F5E6` | 推荐动作、可执行方案 |
| 浅黄色 | `#FFF7E7` | 数据源、MCP 审计、提醒 |
| 紫色 | `#7446A5` | 次级图表、投诉和结构分布 |
| 青色 | `#16BDE5` | 趋势或剂型辅助系列 |
| 正文 | `#172033` | 主要文字 |
| 辅助文字 | `#667085` | 说明、日期、口径 |

## 3. 组件语言

### 标题与分隔

- 模块标题左对齐、黑体加粗，标题下使用 1px 蓝灰色分隔线。
- 标题不使用装饰性图标，依靠字号、留白和分隔线形成层级。

### KPI 卡

- 深海军蓝底、白色大数字、浅灰小标签。
- 每张卡只放一个主数字，比较值或状态作为次级文字。
- 3-4 张卡排成一行，移动端自动堆叠。

### 数据表

- 表头使用主蓝或深蓝底色，白字。
- 表格主体白底，行间使用浅灰细线，不使用斑马纹或强色块。
- 长文本允许换行；数字列右对齐；缺失数据统一显示“未获取”。

### 标签

- 使用低饱和浅色标签：浅红、浅绿、浅黄、浅蓝、浅紫。
- 标签只用于产品属性、风险或证据状态，不能替代正文解释。

### 结论和行动卡

- 浅紫卡表示结论、范围和限制。
- 浅绿卡表示下一步动作或推荐方案。
- 浅黄卡表示数据源、MCP 状态和审计说明。
- 左侧可增加 3-4px 对应颜色边线。

## 4. 图表规则

- 趋势使用折线图；类别比较使用横向条形图；少量构成才使用环形图。
- 图表放在白色圆角卡内，主色控制在蓝、紫、青三组，不使用渐变。
- 坐标轴和网格线保持浅灰，图表标题使用黑色中粗字。
- 图表旁必须有一句结论和一句决策含义，不能只展示图形。

## 5. algae calcium 报告映射

| 参考模块 | 藻钙报告对应内容 |
| --- | --- |
| 买手/运营一句话判断 | VERIFY 决策与核心原因 |
| 深色 KPI 卡 | 精确词月搜索量、类目月销量、Google 趋势、差评样本量 |
| 设计趋势图 | Amazon 搜索趋势、类目销量趋势、竞争集中度 |
| 产品明细表 | 严格藻钙竞品表 |
| 机会矩阵 | 市场容量、竞争、差异化三道门 |
| 改款方案 | 剂型、稳定性、服用体验和信息表达改进 |
| 数据源/MCP 审计 | Sorftime、SerpApi Google Web Trends、Tavily 的口径与限制 |
| 数据源统计 | 调用总数 KPI、Tool/API 调用明细、返回数据规模与统计口径 |
| 主调研词自动选择 | 输入词→主词、固定公式、候选词 R/I/C/S、得分与淘汰原因 |

## 6. 不照搬的内容

- 不使用社交媒体封面的红色大字遮罩。
- 不制作与当前任务无关的九宫格商品改款图。
- 不为了视觉饱满而加入没有数据支撑的环形图或装饰图。
- 不把广义 Calcium 类目数据冒充严格藻钙子市场数据。
