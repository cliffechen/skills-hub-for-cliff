## 1. 目标

把用户输入词视为研究起点，不要默认把它作为最终调研词。先寻找 Amazon 站内最契合消费者购买路径、有效相关流量最大且能够代表目标市场的关键词，再让该词自动接管后续市场、竞争和差评研究。

当种子词已经无法代表消费者发现和购买同一组产品时，标记关键词漂移。品牌词不是通用类目词的字面同义词；品牌词族上涨既可能揭示真实购买路径，也代表品牌截流风险。

## 2. 候选词生成

先让 LLM 根据产品概念生成 15-25 个候选词，并覆盖以下维度：

- 通用类目、同义词和原料来源；
- 明确的产品形态；
- 功效、人群和配方组合；
- 品牌根词和品牌产品词；
- 空格、拼写、缩写和语音变体；
- 可能相关但更宽泛的产品词。

再调用 Sorftime `keyword_extends` 补充真实站内相关词。统一小写、去除重复项，并把最终候选池控制在 30 个以内。LLM 只负责生成和分类候选词，不得猜测搜索量、相关率、销量或最终得分。

## 3. 词型分类

| 分类 | 含义 | 示例 |
| --- | --- | --- |
| `generic_core` | 用户输入的通用成分或类目词 | algae calcium |
| `generic_synonym_source` | 同义词或原料来源词 | red algae calcium、Aquamin calcium |
| `exact_product_category` | 明确产品类目或剂型词 | algae calcium supplement |
| `benefit_formulation` | 功效、人群或配方组合词 | calcium D3 K2、bone health women 50+ |
| `brand_root` | 品牌核心查询词 | algaecal |
| `brand_product` | 具体品牌产品或配方词 | algaecal plus |
| `brand_variant` | 品牌拼写、空格、缩写或语音变体 | algae cal |
| `broad_product` | 可能相关但范围过宽的产品词 | algae supplement |
| `informational` | 信息查询而非直接购买词 | algae calcium benefits |
| `noise` | 不同意图或产品类别 | algae omega |

## 4. Sorftime 验证漏斗

按以下顺序控制调用量：

1. 对去重后的候选词调用 `keyword_detail`，记录当前月搜索量。
2. 根据搜索量和语义相关性保留前 5-8 个候选词；始终保留种子词。
3. 对入围候选调用 `keyword_search_results`，获取前 20 个自然结果。
4. 按目标产品概念逐个标记严格相关产品，并记录 ASIN、品牌、剂型和月销量。
5. 比较候选词与种子词的自然结果重合度。
6. 运行 `scripts/analyze_keyword_drift.py`，自动选择主调研词。
7. 对主调研词和得分最高的 2-3 个辅助词调用 `keyword_trend`，补齐趋势后重新运行脚本。
8. 使用最终主调研词执行后续完整 Amazon 调研；把种子词和非品牌词篮子保留为对照。

不要把结果页商品月销量称为该关键词贡献的销量。只能称为“该关键词结果页严格相关产品承载的预估月销量”。

## 5. 入围硬门槛

候选词必须同时满足：

- Top20 Listing 严格相关率不低于 70%；
- Top20 至少有 10 个严格相关产品；
- 购买意图系数不低于 0.70；
- 与种子词结果重合度不低于 40%，或者目标产品概念相关率不低于 80%；
- 搜索量、严格相关率和市场覆盖度均可计算。

不满足门槛的词保留在审计表，但不得参与主调研词排名。

## 6. 固定评分公式

使用固定公式，不允许 LLM 在单次任务中修改系数：

```text
主调研词得分
= 月搜索量 V
× 严格相关率 R
× 购买意图 I
× 市场覆盖度 C
×（0.85 + 0.15 × 销量支持百分位 S）
```

该分数用于候选词排序，不代表独立消费者数、真实成交归因、TAM 或市场份额。

### 6.1 严格相关率 R

```text
Listing相关率 = Top20严格相关产品数 ÷ Top20产品数
销量相关率 = 严格相关产品月销量 ÷ Top20全部产品月销量
R = Listing相关率 × 70% + 销量相关率 × 30%
```

当结果页缺少完整销量时，只使用 Listing 相关率，并在输出中标记 `listing_only`。不要猜测销量相关率。

### 6.2 购买意图 I

| 分类 | I |
| --- | ---: |
| `brand_product` | 1.00 |
| `brand_root` | 0.95 |
| `brand_variant` | 0.90 |
| `exact_product_category` | 0.90 |
| `generic_core` | 0.80 |
| `generic_synonym_source` | 0.80 |
| `benefit_formulation` | 0.70 |
| `broad_product` | 0.55 |
| `informational` | 0.35 |
| `noise` | 0.00 |

### 6.3 市场覆盖度 C

```text
ASIN覆盖率 = 严格相关ASIN数 ÷ min（20，参考产品池ASIN数）
品牌覆盖率 = 严格相关品牌数 ÷ min（10，参考产品池品牌数）
剂型覆盖率 = 已覆盖剂型数 ÷ 参考产品池主要剂型数

原始覆盖度 Craw
= ASIN覆盖率 × 60%
+ 品牌覆盖率 × 30%
+ 剂型覆盖率 × 10%

C = Craw × 词型覆盖上限
```

| 分类 | 词型覆盖上限 |
| --- | ---: |
| `generic_core`、`generic_synonym_source`、`exact_product_category` | 1.00 |
| `brand_root` | 0.90 |
| `brand_variant` | 0.85 |
| `benefit_formulation` | 0.75 |
| `brand_product` | 0.60 |
| `broad_product` | 0.55 |
| `informational` | 0.30 |
| `noise` | 0.00 |

词型覆盖上限用于防止具体品牌产品词仅凭大流量劫持整个市场研究。

### 6.4 销量支持 S

把每个入围词的严格相关结果页月销量放入同一候选集合，计算其百分位，范围为 0-1。销量修正乘数为 `0.85 + 0.15 × S`，最多影响最终分数 15%。

销量只作为商业活跃度支持和同分候选的辅助判断，不能冒充关键词成交归因。缺少销量时使用乘数 1.00，并明确标记未获得销量支持百分位。

## 7. 自动接管规则

按最终得分从高到低排序，并执行：

1. 选择得分最高且通过全部硬门槛的词作为 `primary_research_keyword`。
2. 当主词不同于用户输入词时，把 `keyword_handoff` 设为 `true`。
3. 使用主词完成市场容量、Top20、竞争、价格带和差评研究。
4. 在报告开头显示“用户输入词 → 主调研词”和接管理由。
5. 保留得分最高的品牌词、品牌产品词、拼写变体和非品牌词篮子作为辅助分析。
6. 当没有候选词通过硬门槛时，不得自动换词；把选择状态设为 `insufficient_evidence`，继续使用种子词仅作探索，并把市场门保持为 `VERIFY`。

例如，`algaecal plus` 可能拥有最高原始流量，但它是具体品牌产品词；当 `algaecal` 具有更完整的市场覆盖度并获得更高最终得分时，应让 `algaecal` 接管完整调研。

## 8. 解释边界

- 不要把多个关键词搜索量直接相加后称为独立消费者数或类目规模。
- 分别建立非品牌词篮子和品牌词族篮子。
- 使用品牌词识别真实购买路径、品牌认知和截流风险，不要把品牌词量视为新品牌可直接获得的需求。
- 将 Google Web 趋势与通过验证的 Amazon 关键词篮子比较，不要只与种子词比较。
- 当精确词下降、至少两个相关词同比增长不低于 15%，且一个关键候选词与种子词结果重合度不低于 50% 时，标记关键词漂移。
- 当只有品牌词族上涨时，标记 `brand_family_keyword_drift_confirmed`，并保持品牌与非品牌需求分离。

## 9. 报告要求

完整 Markdown 和 HTML 报告必须包含：

- 用户输入词、主调研词、是否发生自动接管；
- 固定评分公式和硬门槛；
- 所有候选词的分类、搜索量、R、I、C、S、最终得分和淘汰原因；
- 主调研词接管理由；
- 已验证关键词之间的自然结果重合度；
- 非品牌需求与品牌截流的独立结论；
- 被排除的宽泛词和噪声词；
- 缺失字段及其对主词选择可信度的影响。

如果主词选择证据不足，把 `primary_keyword_selection` 保存为 `missing`，并保持 `VERIFY`。
