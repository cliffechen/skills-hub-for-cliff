# 趋势判读规则（需求端）

所有阈值都是可调起点，不是平台规则；报告里写明本次用了什么值，并至少给一组放宽/收紧后的结果对比。

## 1. 先做数据体检
- 历史长度：站内搜索 ≥24 个月才谈季节性；12–23 个月只谈"疑似"；<12 个月不谈季节。
- 基数：月搜索量很小的词，增长率会被放大。用"增长率 + 绝对量"双门槛，并标记基数效应。
- 口径：搜索量（ABA）是估算；销量是第三方估算；排名不是销量。不同源口径不同，并列展示，不取平均。
- 异常排除：促销月、品牌自带流量、站外一次性事件（新闻、网红）、评论合并、断货造成的排名假跌。

### 1.1 脉冲与单品事件（先剔除，再判读）
- **单月/单周尖峰**：某期值 > 序列中位数的 2.5 倍，且前后期回归正常、同月销量（头部单品或类目）没有同步放大 → 判为脉冲（大促抢跑、站外爆帖、数据异常），不进入趋势与季节判断。在序列里保留原值，但在结论里写明"已剔除 YYYY-MM 脉冲"。
- **脉冲会污染工具结论**：SIF `market_get_keyword_demand` 的 `peak_month` / `weeks_to_peak` / `yoy_change`，以及 Sorftime `keyword_extends` 的 seasonality 文本，都会被单个尖峰带偏（实测：一次 11 月尖峰让两家都把旺季判成 11 月）。规则：**工具给出的峰值月必须用多年曲线复核**；若峰值月只在某一年出现、其他年份同月无峰，改用多年重复出现的峰值区间，并在 `peak_basis` 写明"覆盖了工具的 peak_month"。
- **单品事件**：头部 ASIN 的 BSR/日销出现一夜台阶式变化（如 BSR 一天内恶化 50% 以上并持续），通常是该 Listing 自身的问题（变体调整、断货、被压制、改价），不能直接当作市场需求变化；需用类目销量或其他头部 ASIN 交叉核对。
- **措辞迁移**：同一需求下一个词降、近义词升（如 "beef liver … for women" 降、"beef organ … for women" 升），判为需求换说法，不是需求消失；结论写清迁移方向，衰退词放弃、承接词跟进。

## 2. 七类趋势原型

| 原型 | 判定条件（起点） | 对应建议 |
|---|---|---|
| 结构性增长 | 同比为正且近 3 个月为正；多年低点逐年抬升；≥2 源同向 | 推荐 |
| 加速新兴 | 历史不足 2 年或基数小，近 3 个月增长明显加速；站外先动、站内跟上 | 观察→推荐（看证实信号） |
| 真季节性 | ≥2 个年度在相近月份起峰；搜索量、类目销量节奏一致 | 按峰值倒排判断；看预测时点是否落在上升段 |
| 成熟平稳 | 同比 ±10% 内，波动小，需求结构稳定 | 观察（需求端无增量） |
| 见顶回落 | 增长转为减速，动量"见顶回落"，或连续 ≥3 个月环比走弱 | 观察/放弃 |
| 一次性脉冲 | 单一峰值，无多年重复，站外热度同步消失 | 放弃 |
| 结构性下滑 | 同比为负且多年低点逐年下移；精确词与词根同降 | 放弃 |

## 3. 季节性（真假判断）
真季节性需同时满足：①至少两个年度的峰值落在相近月份；②搜索量、类目销量（或价格）三者中至少两个节奏一致；③有可解释的场景（节日、天气、学期、年度目标）。
单次峰值、只有一个信号动 = 不是季节性，归"一次性脉冲"或"观察"。
SIF `season_position` 与 `weeks_to_peak` 是起点，要用多年曲线核对峰值月份；`seasonal_strength` 为数据不足时，不得写"无季节性"，写 UNKNOWN。

## 4. 领先–滞后链
站外（Google / TikTok / Reddit）→ 站内搜索（ABA）→ 类目销量 → 新品销量占比。
- 上游先动、下游跟上：趋势成立，且已走到链条哪一环要写明。
- 只有上游动：早期，结论"观察"，证实信号 = 站内搜索连续 N 周抬升。
- 下游强、上游无：可能是促销/运营驱动，回头排除异常。

## 5. 需求流向（进入窗口）
- 新品销量占比在上升、点击集中度下降、`conversion_gap` 为 true：需求在外溢，窗口开。
- 点击和转化都高度集中于少数 ASIN 且持续多月不变：窗口关。
- 只下"需求流向"结论，不下"能不能做出来"的结论。

## 6. 置信度
- 高：≥3 个独立源同向，且站内历史 ≥24 个月，无明显异常。
- 中：2 个独立源同向；或历史 12–23 个月。
- 低：只有 1 个源，或源之间冲突，或历史 <12 个月。
- 低置信度的候选结论最多"观察"。

## 7. 预测输出模板（每个候选）
- **方向与阶段**：原型 + 当前所处位置（上升初期/旺季中/回落段/低谷）。
- **预测时点判断**：到 `forecast_target_date` 时处于什么位置；距下一峰/谷多少周（附峰值月份依据）。
- **三情景**（各 1–2 句，说明依赖什么）：保守（趋势减速/提前见顶）、基准（延续历史节奏）、乐观（站外新驱动持续）。
- **置信度**：高/中/低 + 一句依据。
- **证实信号 / 证伪信号**：各 2–3 条，写清看哪个工具的哪个指标、什么时候复查。
- 固定尾句：本结论不含供给与利润判断。

## 8. 不得做的事
不用单一增长率下结论；不把一次峰值外推成趋势；不把搜索量当销量；不拿 CPC 算盈亏；不从原产品销量外推到场景扩展出的新产品（新方向需独立验证精准词和需求）。
