# ds-entry-quickcheck · 保健品成分入场速判

用跟随者的视角回答一个问题：**这个成分现在跟进，晚不晚、好不好推？**

输出是一句结论加逐点分析，以文字为主。每一点先说看到了什么（最多一两个关键数字），再说这说明什么：

> **urolithin 现在跟进：谨慎。** 主要卡在两点：一是后来者里已有 5 个站稳，好位置在被占；二是核心词转化约 10%，只到观望档。
>
> - **入场曲线**：截至 8 月，约 130 个品牌在卖，其中最近 3 个月就进来约 80 个（约占 61%）。入场潮还在加速、没到顶——今天进场按现有人数算排在后面，但最终进场的人会比现在多得多。
> - **供需对比**：近 3 个月的搜索量是半年前的 1.7 倍，同期在卖的品牌数是 3.2 倍。供给追得比需求快，窗口在收窄，但还没关。
> - **后来者卖得动吗**：最近 3 个月进场的约 80 个新品里，约 35% 月销已经过 100。后来者还卖得动。
> - **新头部**：近一年进场的新品里已经有 5 个站稳了——后来者做得起来，但好位置在被一个个占掉。
> - **好不好推**：每 100 个点击大约出 10 单，落在观望档（10–12%）。长尾词「urolithin a gummies」转化更高（约 14%），可以作切入词。

## 五个指标
| 指标 | 看什么 |
|---|---|
| 近期批次出单率 | 最近 3 个月进场的新品里，有多少月销已经过 100 |
| 需求增速 ÷ 供给增速 | 同一个半年窗口里，搜索量和在卖品牌数谁涨得快 |
| 入场加速度 | 进场是在加速、平稳还是放缓 |
| 新头部 | 近一年进场的新品里，有几个评分数已经过 300 |
| 核心词转化率 | SIF 的点击→购买 CVR，分五档：<8% 不建议，8–10% 谨慎，10–12% 观望，12–15% 潜力，≥15% 重点关注 |

综合后给出 **可跟进 / 谨慎 / 不建议 / 数据不足**。指标定义、阈值、截断处理和叙述规则见 [`references/metrics.md`](./references/metrics.md)。

## 三档
- **lite**：单个成分的结论和 5 点分析。
- **plus**：在 lite 基础上，最多再加 3 点有信息量的补充（剂型差异、新品定价、卖家构成、近期热度）。
- **compare**：2–5 个成分并排，先给排序结论，再每个成分一句"亮点 / 卡点"。

## 前置条件
- Python 3.10+，并安装 `httpx`（`pip install httpx`）。
- 已配置两个 MCP，且都是 HTTP 端点：**卖家精灵**（`sellersprite`）和 **SIF**（`sif`）。脚本会直接调用它们：
  - 默认从 `~/.claude.json` 的 `mcpServers.sellersprite.url` / `mcpServers.sif.url` 读取端点。
  - 也可以用环境变量 `SELLERSPRITE_MCP_URL` / `SIF_MCP_URL` 指定。
  - 密钥只在运行时读取，不写入任何输出文件，也不出现在报错信息里。

## 用法
```bash
python scripts/entry_check.py lite    --query "urolithin" --demand "urolithin a"
python scripts/entry_check.py plus    --query "goldenseal,golden seal" --demand "goldenseal"
python scripts/entry_check.py compare --items "urolithin|urolithin a; lymphatic|lymphatic drainage drops|3760901:23675621011"
```
Windows 下建议设置 `PYTHONUTF8=1`。常用参数：
- `--node`：类目节点，只看补充剂用 `3760901:23675621011`。
- `--max-pages`：大品类商品多时调到 20，避免样本截断。
- `--tables`：在对话里同时打印明细表。
- `--html`：另外生成带图的离线报告。默认不生成。

输出在当前目录的 `entry-check/` 下：`card.md`（分析要点）、`tables.md`（明细表）、`data.json`。调用结果缓存在 `~/.cache/ds-entry-quickcheck/`，重跑不会重复消耗额度。

## 不做什么
只判断入场时机和推广难度，不做利润、成本、供应链判断。合规风险词只提示，不参与判定。所有数字都是卖家精灵和 SIF 的估算值。
