# 指标定义（ds-entry-quickcheck）

## 样本
- **供给**：卖家精灵 `product_research`，`matchType=1`（标题词组匹配），类目节点 `--node`，按上架时间倒序，每页 40 条，翻到底或到 `--max-pages` 为止。多个 query 的结果按 ASIN 合并。
- **父体去重**：同一父体的进场时间取所有子体中最早的上架日；月销和评分数取子体中的最大值（卖家精灵的月销、评分数本身就是父体级的，子体之间会重复）。
- **需求**：卖家精灵 `aba_research_trend` 月度搜索量。
- **截止月 M**：需求序列里最新的非零月份。供给只统计到 M 月底；M 之后进场的父体单独列出，不进指标。
- **转化**：SIF `market_screen_keyword_opportunities(keyword_root=需求词)`，取与需求词完全相同的那一行；同一返回里以该词开头的长尾词（最多 5 个）一并列出。对照值来自卖家精灵 `keyword_miner(keywordList=[需求词])` 的 `purchaseRate`。

## 指标
| 指标 | 公式 | 读法 |
|---|---|---|
| I1 近期批次出单率 | M-2..M 进场的父体中，当前月销 ≥ `min_units`（默认 100）的比例。进场父体少于 5 个时不计算，显示"样本少" | 最近进场的人里还有多少能卖起来 |
| I2 需求增速 ÷ 供给增速 | 需求增速 = avg(M-2..M) ÷ avg(M-8..M-6)；供给增速 = 截至 M 的累计父体数 ÷ 截至 M-6 的累计父体数 | 小于 1 说明供给涨得比需求快 |
| I3 入场加速度 | (M-2..M 新父体数) ÷ (M-5..M-3 新父体数)；>1.2 为加速，<0.8 为放缓；两个窗口合计少于 6 个时显示"样本少" | 还在加速，说明入场潮还没到顶 |
| I4 新头部 | 近 12 个月（相对今天）进场、评分数 ≥300 的父体个数 | 后来者里已经有人站稳了 |
| I5 核心词 CVR | SIF `cvr`：点击→购买转化率（`clickPurchaseRateT7`，最新统计周） | 买家点进来后有多少下单，直接决定推广难度 |

### 三种"转化率"口径（不要混用）
| 口径 | 来源 | 含义 | 在本 skill 中的用途 |
|---|---|---|---|
| 点击→购买 CVR | SIF `cvr` | 下单数 ÷ 点击数（7 天归因，周度） | **I5，参与判定** |
| 搜索→点击率 | SIF `search_ctr_week` / `search_ctr_90d` | 点击数 ÷ 搜索数。SIF 官网"关键词转化率"页面显示的就是它 | 只展示 |
| 搜索→购买率 | 卖家精灵 `purchaseRate` | 购买数 ÷ 搜索数（月度） | 只作对照 |

实测（2026-09/08）：lymphatic drainage drops 的 SIF CVR 12.8%、卖家精灵购买率 3.9%；urolithin a 分别是 10.1% 和 5.8%。两种口径给出的高低排序是相反的。

## 判定（起始阈值，见 `entry_check.py` 里的 `TH`）
1. **数据不足**：截至 M 的父体少于 15 个，或没有需求数据。
2. **不建议**：I1 < 15%，或 I2 < 0.3（I2 为截断下限值时不参与这条判断），或 I5 < 8%。
3. **可跟进**：需求增速 ≥ 1.0，且 I1 ≥ 25%，且 I2 ≥ 0.5，且 I4 ≤ 1，且 I5 ≥ 12%。I5 缺失时不能判可跟进。
4. **谨慎**：其余情况。卡片会列出是哪几条没满足。

### 核心词转化率分档（用户定，见 `TH["cvr_tiers"]`）
| SIF CVR | 档位 | 对整体判定的影响 |
|---|---|---|
| < 8% | 不建议 | 整体直接判"不建议" |
| 8–10% | 谨慎 | 整体最高到"谨慎" |
| 10–12% | 观望 | 整体最高到"谨慎" |
| 12–15% | 潜力 | 不拖后腿，可以判"可跟进" |
| ≥ 15% | 重点关注 | 可以判"可跟进"；结论句里单独点出来，即使整体是谨慎或不建议也会提 |

注：用户给的分档是"12–14% 潜力、15% 以上重点关注"，14–15% 之间暂时归到潜力。

compare 排序：判定档位 → 需求是否在增长 → I5 → I1 → I2。

## 样本截断（翻到 `--max-pages` 仍未取完）
截断丢掉的是**最老**的商品，所以按以下规则处理：
- **累计占比**标 `*`：老品被漏掉，这一列会偏高。
- **I1**：近 3 个月的批次如果没有被完整覆盖（样本最早月份晚于 M-2），显示"截断无法计算"。
- **I2**：
  - 样本能覆盖到 M-6 以前时，截至 M 和截至 M-6 两个累计数漏掉的是同一批老品，观察到的供给增速偏高，所以 I2 是**下限**，显示为 `≥x`。下限值可以用来判断"过线"，但不能用来判"不建议"。
  - 样本覆盖不到 M-6 时，不计算。
- **I3**：样本覆盖不到 M-5 时，显示"截断无法计算"。
- **I4**：样本覆盖不到 12 个月前时，显示为 `≥x`。
- **叙述里怎么说**：样本覆盖到 M 往前 12 个月以上时，只提一句"漏掉的是更老的商品，不影响判断"，不加"至少"；覆盖不到 12 个月时，才在数字前加"至少"，并建议加大页数重跑。

## 叙述规则（`scripts/narrate.py`）
输出是"结论句 + 逐点分析"，每一点 = 事实（最多 1–2 个数字）+ 说明什么。数字取约数：小于 20 的取精确值，100 以内按 5 取整，1000 以内按 10 取整；百分比取整，倍数保留 1 位小数。表格只放在 `tables.md`、`--tables` 打印和可选的 `--html` 报告附录里。

| 要点 | 事实 | 说明什么（按条件选一档） |
|---|---|---|
| 结论 | 判定 | 可跟进 → "需求在涨、后来者卖得动、转化也够"；其他 → "主要卡在 …"，取最关键的 1–2 个卡点 |
| 入场曲线 | 在卖品牌数、近 3 个月新进数（占比）、截止月之后新进数 | 加速 → 入场潮没到顶，现在进按人数算靠后，但最终人数会多得多；平稳；放缓 → 降温；样本少 → 没人在追 |
| 供需对比 | 需求倍数、品牌数倍数 | 需求 <1 → 在缩；I2 ≥1 → 窗口开着；0.5–1 → 在收窄；<0.5 → 基本关了 |
| 后来者卖得动吗 | 近 3 个月新品数、出单比例 | ≥25% → 还卖得动；15–25% → 只有一部分能卖起来；<15% → 大多卖不动 |
| 新头部 | 站稳的个数，点名 1–2 个 | 0 → 位置空着（也可能难做大）；1 → 坑位还多；>1 → 好位置在被占 |
| 好不好推 | 每 100 次点击的出单数、每单点击费 | 按上面的五档措辞：<8% 不建议（很吃广告）；8–10% 谨慎（推广成本高）；10–12% 观望（单靠这个词推不划算）；12–15% 潜力（有推起来的潜力）；≥15% 重点关注。只有附加词是剂型、人群、规格这类通用词的长尾词，CVR 高出 3 个百分点以上、周搜索 ≥200 时，才推荐为切入词（不推荐品牌长尾） |
| plus：剂型、价格、谁在跟、近期热度 | 只写有信息量的，最多 3 条 | 剂型只比较进场数 ≥10 的；价格差 ≥10% 才写；中国/香港卖家 ≥70% 才写；周度形态是脉冲时才写 |
| 需要留意 | 最多 2 条 | 优先级：样本截断 → 需求某月环比 ≥3 倍的跳变 → 合规词 → 在卖品牌太少 → 导航型需求 |

compare：第一句按判定分组排序，然后每个成分一句"亮点是…；卡点是…"。

## plus 档另加
- 近 6 个月（M-5..M）进场者的剂型拆分：按标题正则分成软糖、软胶囊、胶囊、粉、片剂、滴剂、液体、贴片、其他，给出各自的进场数和出单率。
- 价格带：近期进场者 vs 老品，中位数和 P25–P75。
- 近期进场者里中国/香港卖家的占比。
- 需求词的前三品牌和前三点击集中度（≥75% 偏品牌或导航型需求）。
- 需求词的周度形态（steady_rise / new_rising / pulse / flat），用最近 16 周判断，规则同 `trend_filter.py`。

## 已知局限
- 月销是**当前**估算值，不是进场当月的值；越新的批次，出单率越容易偏低（还没起量）。
- 只覆盖标题里含 query 的商品。成分的别名、拼写变体要手动加进 query。
- 类目节点选窄了会漏掉商品（例如蛋白粉不在补充剂节点下）；选宽了可能混进同名的非补充剂或器械。
- 需求是单个 ABA 词，不是整个成分的总需求。个别月份可能出现异常峰值，看曲线时留意。
- SIF 的 CVR 只是一周的值，而且受 7 天归因窗口影响；它和需求、供给数据（截止月 M）在时间上不完全对齐。SIF 未收录的长尾词没有 CVR。
- 线上数据会更新，同一天重跑可能有个位数的差异；缓存在 `~/.cache/ds-entry-quickcheck/`，加 `--no-cache` 可强制刷新。
