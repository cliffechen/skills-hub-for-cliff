# GinvAds 广告工作台

此目录为可独立运行或发布的静态工作台源码。`dist/` 包含完整 HTML、CSS、JavaScript、五个计算引擎和知识数据。它是本仓库中的普通源码目录，不包含嵌套 Git 仓库或私人托管配置。

内容包含 13 个主题、54 篇方法论、20 张概念卡、5 个可交互计算工具。界面使用白色、细分隔线及钴蓝色侧板；支持全文搜索、完整主题阅读、单篇阅读和窄屏布局。

采集快照日期：2026-09-30（Asia/Shanghai）。原始来源：https://sellerhelp.top/projects/Ginv-Ads%E5%B9%BF%E5%91%8A%E6%99%BA%E5%BA%93/

完整本地采集归档、启动脚本、公式审计与验证文件存放在上一级 `ginv-ads-workbench/` 项目目录。开发时直接编辑 `dist/`；本项目无打包或依赖安装步骤。在上一级运行 `npm start` 可预览，也可使用任意本地静态网页服务查看 `dist/`。自行托管时发布 `dist/` 目录。
