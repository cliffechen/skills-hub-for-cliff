## 2. 输入、默认值、单位和精确公式

以下 `CVR` 与 `ACoS` 公式里的变量都是小数比例。用户输入 `10` 表示 `10%`，计算时转成 `0.10`，不是输入 `0.10` 表示 `10%`。

| 工具 | 原函数 | 输入及默认值 | 精确计算 | 原站显示规则 | 默认结果 |
| --- | --- | --- | --- | --- | --- |
| 盈亏平衡 ACoS | `calBeAc` | 售价 `t1p=29.99` USD；单件毛利 `t1m=9` USD | 售价 > 0 时 `毛利 / 售价 × 100`，否则 `0` | `toFixed(1)`，百分比 | `30.0%` |
| 单点击期望价值 EV | `calEv` | 转化率 `t0c=10`%；单件毛利 `t0m=9` USD；当前 CPC `t0p=1` USD | `EV = (转化率 / 100) × 毛利`；`净期望 = EV − CPC` | EV、CPC、净期望各 `toFixed(2)`；净期望 ≥ 0 进入正期望分支 | EV `$0.90`；净期望 `−$0.10`，负期望 |
| 反推保本 CPC | `calCpc` | 目标 ACoS `t2a=25`%；转化率 `t2c=10`%；客单价 `t2p=30` USD | `(目标 ACoS / 100) × (转化率 / 100) × 客单价` | 乘积 > 0 才输出，`toFixed(2)` | `$0.75` |
| 保底日预算 | `calBud` | 转化率 `t3c=10`%；单次出价 CPC `t3p=1` USD | `所需点击数 = ceil(1 / CVR)`；`预算 = 所需点击数 × CPC` | 点击数向上取整；预算 `toFixed(0)`，整数美元 | `10` 次点击、`$10` |
| 高点击阈值 | `calHc` | 平均转化率 `t4c=10`% | `平均点击数 = 1 / CVR`；`阈值 = 平均点击数 × 1.5` | 平均点击数 `toFixed(1)`；阈值 `toFixed(0)` | 平均 `10.0` 次、阈值 `15` 次 |

补充实现细节：

- 五个输出框初始为空，源页面点击对应“计算”按钮时更新结果，没有自动初算。
- 所有输入都是 `type="number"`，源 HTML 没有 `min`、`max`、`step` 或 `required`。按钮直接执行函数，不借助表单验证。工作台应设置适用的数字限制，支持小数。
- 数值读取统一为 `parseFloat(value) || 0`，因此空输入和解析失败都会被当作 `0`，负数不会被拦截。原站没有显式防止非有限数值。
- `calCpc` 内部另算 `ev = CVR × 客单价`，该变量没有参与输出，也不是按毛利计算的单点击 EV。
- `calBud` 内部另算 `ev = CVR × 1`，只决定是否追加提示文字，没有在检查当前 CPC 与真实毛利 EV 的大小。
- 高点击工具介绍写“1.5–2 倍”，**实际函数只算 1.5 倍**。不能声称原站已经实现 2 倍上限。可额外展示 2 倍参考，但必须标明这是工作台补充。

## 3. 边界行为（忠实记录）

| 工具 | 原站处理 | 应特别核对的实际行为 |
| --- | --- | --- |
| ACoS | 售价 ≤ 0 返回 `0.0%`；不检查毛利 | 空售价也显示 `0.0%`；负毛利可显示负 ACoS；毛利大于售价可显示 >100% |
| EV | 转化率或毛利为 0 时“请填写参数”；CPC 可空或为 0 | 空 CPC 被视为 `$0.00`；负转化率/负毛利/负 CPC 都可能参与运算；`EV=CPC` 被称为“正期望，值得投”，输出利润 `$0.00` |
| CPC | 仅检查最终乘积 > 0 | 任意输入为 0 时“请填写完整参数”；两个负输入相乘会变成正数并获得有效结果 |
| 日预算 | 仅检查转化率/CPC 是否为 0 | 负转化率可输出负点击数、负预算；正转化率始终追加 EV 提示；`100%` 转化率、`$0.30` CPC 会把预算显示成 `$0` |
| 高点击 | 仅检查转化率是否为 0 | 负值会生成负平均/阈值；`200%` 输入仍计算；`12%` 时平均 `8.3`、原阈值 `12.5` 被显示成 `13` |

建议工作台显式校验有限数值，拒绝空必填项、负 CPC、非正售价，以及不在 `(0,100]` 范围内的转化率。ACoS 目标是否允许 >100% 是业务选择；若允许，必须保留提醒。可允许毛利 `0` 并解释“没有广告利润空间”，但不能冒充源站对零毛利的输出。

原站数值公式与显示舍入可以保留。若工作台使用更准确的说明、零利润状态、两位美元预算或输入校验，应在产品说明中区分“按原站公式计算”与“修正原站措辞/输入处理”，不要把修正后的行为写成原站已经具备的功能。

## 4. 原站解释存在的问题与建议

### 4.1 盈亏平衡 ACoS

`毛利 / 售价` 在单件售出且毛利为**扣除广告前**的毛利时成立。默认原始值为 `9 / 29.99 × 100 = 30.010003…%`，显示 `30.0%`。源站括号“每个点击的保本 EV 上限占比”表达含混；更清楚的解释是“广告费占广告销售额的比例达到毛利率时，按此模型广告利润为零”。

不能在毛利已扣除广告费用后再将本公式用于广告利润判断，否则会重复计费。

### 4.2 单点击 EV

这个 EV 是每次点击带来的**期望广告前毛利**，`EV − 实际 CPC` 才是该模型的每次点击净期望。默认 `0.1 × 9 − 1 = −0.10` USD。

源描述说 `EV > CPC` 才值得投，但实现把相等也归入“正期望”。工作台推荐把相等显示为“盈亏平衡”，保持 `EV` 与差额的公式。输入较高转化率不能自动证明广告应投入，模型依赖样本与毛利口径。

### 4.3 “保本 CPC”其实先算目标 ACoS 允许的 CPC

`ACoS × CVR × 客单价` 倒推的是满足目标 ACoS 的平均 CPC 上限。只有当目标 ACoS 等于扣广告前毛利率，才可以称为保本 CPC。这个工具没有毛利输入，无法自行判断是否真正保本。

可用工作台名称“目标 ACoS 对应 CPC”，并保留原站名称作为来源标记。原结果的“目标 ACoS 设满”应解释为“目标 ACoS 等于盈亏平衡 ACoS”。计算结果是平均点击成本的上限；平台设置的竞价及广告位调整可能与实际 CPC 不同，不应把两者当成相同保证值。

### 4.4 “保底日预算”不保证出单

`1 / CVR` 是平均每单点击数。原公式先向上取整，再乘 CPC，是按约一单点击量估算的预算。它不是必然出单所需的最低预算。若每次点击以 `10%` 独立概率成交，10 次点击仍无成交的概率是 `(1−0.10)^10 ≈ 34.9%`。此数值用于说明数学含义，不是对广告效果作保证。

推荐说明“按当前转化率估算的一单点击预算”，保留原始公式 `ceil(1/CVR) × CPC`。不要复用源函数 `CVR×1` 当作毛利 EV；该工具没有毛利输入，无法判断是否亏损。可保留一条一般性说明“盈利还需结合毛利与 CPC 判断”。

舍入例：CVR `7%`、CPC `$0.90`，原站计算 `ceil(14.2857…) = 15` 次，预算实际为 `$13.50`，原输出舍入到 `$14`。工作台若展示 `$13.50`，应确认这是显示精度改进，公式仍相同。

### 4.5 高点击阈值是经验参考

原始阈值等于平均出单点击数的 `1.5` 倍，不能视为统计显著的自动否定标准。默认 CVR `10%`，15 次点击仍零单的概率在独立恒定概率示例中约为 `20.6%`。建议结果表达“达到经验观察阈值，可复查相关性/出价/转化”，并保留源站的原文供查阅。
