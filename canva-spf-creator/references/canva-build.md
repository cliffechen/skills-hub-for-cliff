# 在 Canva 里建 SPF 页

用 Canva 连接器的工具：`resolve-shortlink`、`read-design`、`merge-designs`、`edit-design`。没有连接器时告诉用户，不要改走浏览器手工拖拽——面板对齐精度做不到。

## 1. 为什么要克隆模板页

`add_text` 新建的文字**不能指定字体**，`format_text` 也只能改字号、粗细、颜色、对齐、行距。要保住品牌字体，唯一办法是复制一页已有的 SPF 页，再改里面的字。所以流程是"克隆 → 改字 → 删多余 → 重排"，不是从空白页画。

## 2. 克隆

```
merge-designs
  type: modify_existing_design
  design_id: <目标设计>
  operations: [{type: insert_pages,
                source: {type: design, design_id: <模板所在设计>, page_numbers: [<模板页码>]},
                after_page_number: <N>}]      # 省略 = 放到最后
```

- 源和目标可以是同一个设计。
- 这一步**不在事务里，立即保存**。用户马上能在设计里看到一页模板副本。
- 如果之前为了看模板页开过事务，先 `finalize: "cancel"` 关掉再克隆。
- 克隆后页面 ID 是新的。马上 `read-design` 取 `page_metadata`，记下新页 ID。**之后每次要用页码前都按 ID 重新查一次**：用户在 Canva 里拖动页面，页码就变了，实测发生过（新页从第 23 页被移到第 14 页）。

## 3. 先打标记，再认槽位

克隆后第一件事：开事务，在新页左上角加标记并立即保存。

```
add_text     page_id: <新页 ID>, text: "create by canva mcp", top: 16, left: 16
format_text  font_size: 32, font_weight: bold        # 默认 16 px 在 1600 页面上看不清
finalize: commit
```

- 页面不是 1600 宽时，字号按页面宽度的 2% 取。
- 面板外框贴近页面顶部时（模板外框 top 约 47），标记放 `top: 4`、字号 28，避免压到外框上边线。
- 左上角被模板内容占了（深色底或有元素）：仍放左上角，深色底时用 `format_text` 把颜色改成白色。
- 之后每次核验都把这个元素算进去；它不见了说明有人动过这页。
- 它是画布上的普通文字，会随页面导出。用户说定稿了，就问一句要不要删。

然后认槽位：`read-design`，`open_transaction: true`，`filter: {fields: ["design_content","thumbnails"], page_indices: [新页码]}`。返回每个元素的 `top/left/width/height`、类型、文字和格式。按几何位置归类，不要按元素出现顺序：

| 槽位 | 怎么认 |
|---|---|
| 标题 | 文字 `Supplement Facts`，字号最大 |
| 份量两行 | 标题下方、左对齐、两个 top 相近的单行文字 |
| 右上角粒数 | 与份量行同高、右对齐（模板可能有，如 `90 Softgel`）。FDA 不要求，来源没给总粒数就删 |
| 表头 | `Amount per serving`、`%Daily Value`，右对齐 |
| 成分行 | top 相近的三个文字为一行：名称（左对齐）、含量（右对齐，中间列）、%DV（右对齐，最右列） |
| 行间细线 | `type: line`，stroke weight 1 |
| 粗线 | `type: line`，stroke weight 20–45 |
| 脚注 | 以 † 或 * 开头的小字 |
| Other Ingredients | 含 `Other Ingredients:` 的多行文字，通常两个 textRegion（加粗标签 + 正文） |
| 外框 | 白底、有 stroke 的大矩形 shape，包住以上全部 |
| 品牌栏 | 外框之外的色块、logo、徽章。原样保留 |

名称槽有两种：单行（一个 textRegion，加粗）和双行（两个 textRegion：加粗名称 + 常规字重的来源形式）。记下每个槽是哪种。

## 4. 改内容

一次 `edit-design` 可以带很多 operations，`finalize: "keep_open"`。个别 operation 失败不影响同批其他的，所以每次都要看 `edit_operation_results` 里有没有 `failure`。

| 要做的事 | 用什么 | 注意 |
|---|---|---|
| 改单一格式的文字 | `replace_text` | 保留原字体和格式 |
| 改多格式文字的其中一段 | `find_and_replace_text`，`find_text` 只传那一段的**一部分**，每段至少留一个原字符不动 | 用它保住"加粗名称 + 常规来源"。不要对多 region 元素用 `replace_text`。**不能把某一段整段替换掉**：实测把 `(as cholecalciferol)` 整段换掉后，新文字并入前一段变成了加粗。正确做法是留下括号，只换 `as cholecalciferol`；名称段留下结尾的换行符，只换 `Vitamin D3` 或其中的 `D3` |
| 一行里写多行内容（专利混合物的子成分） | 在替换文字里用 `\n`，子成分前加 4 个空格缩进 | 换行会保留 |
| 文字太长自动折行 | `resize_element` 只传 `width` 加宽 | 35 px 字号每个字符约 20 px 宽。名称元素可以加宽到 900：含量在第一行右侧，来源和子成分在第二行以后，不会相撞 |
| 把加粗的单行槽改成常规字重 | `format_text` 传 `font_weight: normal` | 多出来的单行名称槽可以这样回收，用来放植物成分的部位和规格说明，字体仍是模板字体 |
| 删多余的行、线、标签 | `delete_element` | 组内子元素用完整 locator（`页-组-子`） |
| 移动文字、形状 | `position_element` | **对 line 元素会失败** |
| 移动线条 | `update_line_properties`，传 `start` 和 `end` 的 `top/left` | 这里的 top 是线的**中心** y，不是上沿。粗 42 的线上沿在 y，就传 y+21 |
| 新增粗线 | `insert_shape`，矩形 path `M0 0H64V64H0z`，viewBox 64×64，颜色取模板粗线的颜色 | 线条不能新建也不能复制，用扁矩形代替 |
| 调外框高度 | `resize_element`，width 和 height 都传 | |
| 改元素颜色 | `recolor_element` | |

行的分配：
- 需要的行数 ≤ 模板行数：挑槽位类型匹配的行来用（有来源形式的成分用双行槽，没有的用单行槽），其余删掉。
- 把双行槽当单行用：`find_and_replace_text` 把第二段（`\n(as ...)`）替换为空串试一次；返回的 document 里若仍残留空行，改用单行槽。
- 需要的行数 > 模板行数：见 §7。

## 5. 排版

以克隆来的模板为准量出这些值，不要写死。下面是在 1600×1600、字号约 35 px 的模板上实测可用的一组，供参考：

| 项 | 值 |
|---|---|
| 单行成分行高（文字高度） | 约 41 |
| 双行成分行高 | 约 74 |
| 行内上下留白 | 各约 19 |
| 细线到下一行文字 | 约 19 |
| 有 DV / 无 DV 之间的粗线 | 高 10 |
| 表尾粗线 | 沿用模板（42） |
| 表尾粗线到脚注 | 约 19 |
| 脚注到 Other Ingredients | 约 12 |
| Other Ingredients 行距 | 每行约 46；1115 宽、33 px 字号时每行约 62 个字符 |
| 外框底边到最后一行内容 | 约 24 |

步骤：
1. 从表头下的线开始，自上而下给每一行算 top：`上一行底 + 留白`。每行的名称、含量、%DV 三个元素 top 相同。
2. 行与行之间：同类之间放细线（把模板里保留的细线用 `update_line_properties` 挪过去，不够就少放，不要用 shape 冒充细线——1 px 的 shape 在缩略图里粗细不一致）；有 DV 与无 DV 之间放粗线。
3. 最后一行下面放表尾粗线、脚注。
4. 外框收到脚注下方约 24，Other Ingredients 放在框外，离外框底边约 24，左边与框内文字对齐。即使模板把它放在框内，也按框外做。
5. 改完 Other Ingredients 的字以后，从返回的 document 读它的实际 `height` 再定外框和后续元素位置——行数只能改完才知道。
6. 面板比模板短很多时，整体下移让它在品牌栏上方的空间里垂直居中（所有面板元素加同一个偏移量），不要拉大行距去填。面板比可用空间长时，先告诉用户，再考虑整体缩小字号。

7. 含量和 %DV 对齐名称的**第一行**（top 比名称元素低 2 左右），多行成分尤其如此。模板里双行成分的含量是垂直居中的，统一改成对齐第一行。
8. 行高按实际行数算：双行约 74，每多一行加约 33。改完字先从返回的 document 读每个名称元素的实际 `height`，发现比预期高就是折行了，先加宽再排下面的行。

每批操作后看返回的预览图：标题有没有被粗线压住、行有没有落在框外、右对齐的列是否还对齐、文字有没有被截断、来源形式是不是常规字重、相邻行有没有叠在一起。预览有问题而且牵涉已删除的元素时，`finalize: "cancel"` 丢掉整个草稿重开事务再做一遍，比在坏草稿上修补可靠。

每次 `edit-design` 都返回整页的结构化数据，很大。把改字、删除、定位尽量放进一次调用；只读核验时用 `filter.element_ids` 缩小范围。

## 6. 没有模板页时

按顺序试：
1. 用户的其他设计里找一页 SPF（`search-designs` 搜 `Supplement Facts`），从那个设计克隆。
2. 都没有：告诉用户需要一页模板才能保住字体，问是否接受用 Canva 默认字体从空白页画。同意后用 `add_page` + `add_text` + `insert_shape` 按 `fda-spf-rules.md` §1 搭，并在总结里说明字体是默认字体。

建议用户维护一页"SPF 母版"：15–20 行、单行槽和双行槽各半、含一个专利混合物缩进行。这样任何配方都不会行数不够。

## 7. 接口做不到的事

交付时如实告诉用户，不要绕：

- **不能选字体**，新建文字只能是默认字体。
- **不能复制元素**。行数超过模板时，多出来的行只能用 `add_text` 新建再 `format_text` 调字号粗细颜色，字体会和其他行不同。出现这种情况要在总结里指出是哪几行，请用户在 Canva 里手动换字体，或换一页行数够的模板。
- **不能改单页的页面标题**，克隆页沿用模板页的标题。
- **不能新建线条元素**，只能用矩形代替。
- 保存后缩略图可能长时间是旧的（返回里带 `fallbackstale`）。

## 8. 保存与核验

1. 预览图自查通过后：`edit-design`，`transaction_id`，`finalize: "commit"`，不带 operations。
2. `read-design` 取 `page_metadata`，按页面 ID 找到当前页码。
3. `read-design` 带 `open_transaction: true` 读该页（不开事务拿不到坐标，只有纯文字）。可用 `filter.element_ids` 只取面板元素。逐个元素对比提交前最后一次返回的 document：
   - 文字是新内容，没有模板残留（旧成分名、旧剂型）
   - 每个元素的 `top`、`left` 与草稿一致
   - 多行文字的 `height`：改字后行数变了，height 却还是模板的旧值，说明这个元素的几何信息没刷新，重点看它
   - 文字的 `fontRef` 与同类元素一致
4. 核完 `finalize: "cancel"` 关掉这个只读事务。
5. 有不一致：新开事务补 `position_element` / `resize_element`，commit，回到第 2 步。
6. 事务长时间不提交会失效。commit 报错时：重新开事务读新页，如果内容还是模板原样，就重做第 4–5 节；不要重新克隆。

**实测过的保存后错位**：一次提交里，草稿预览完全正确，保存后 `Servings Per Container` 和 `Other Ingredients` 两个文字元素的文字是新的，位置却回到了模板原坐标（前者压在标题上，后者留在原处、外框里空出一块），其中一个的 `fontRef` 也变了。同一批里其他元素的位置都保住了。当时用户正开着这个设计并拖动过页面，原因没能确定是提交丢了位置，还是编辑器里的旧状态覆盖了它。所以：保存后必须按上面第 3 步核对坐标；提醒用户在生成期间不要在 Canva 里动这一页。

用户说"在设计里没看到"或"位置不对"：依次查——有没有 commit、页面是否被移动了位置、元素坐标是否与草稿一致。先查清再改，不要直接再建一页。
