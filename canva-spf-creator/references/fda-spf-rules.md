# FDA Supplement Facts 规则与缺陷检查表

依据：21 CFR 101.36（膳食补充剂营养标签）、21 CFR 101.9（Daily Value 与取整）、21 CFR 101.4（成分表）。本文件是工作摘要，不是法规全文；遇到这里没覆盖的情况（婴幼儿/孕妇产品、多列面板、小包装简化格式），告诉用户需要对照法规原文或请合规顾问确认，不要凭印象写。

## 1. 面板从上到下必须有什么

| 顺序 | 内容 | 写法 |
|---|---|---|
| 1 | 标题 | `Supplement Facts`，面板里最大的字，加粗，尽量横贯面板宽度 |
| 2 | 份量 | `Serving Size: 3 Gummies`。单位用剂型的常用名（Softgel / Capsule / Tablet / Gummy / Scoop），数量大于 1 用复数 |
| 3 | 份数 | `Servings Per Container: 30`。在份量**下面** |
| 4 | 粗线 | 标题区与表头之间 |
| 5 | 表头 | `Amount Per Serving` 和 `% Daily Value`，右对齐在各自列上 |
| 6 | 线 | 表头下 |
| 7 | 有 Daily Value 的成分 | 按 §2 的固定顺序，每行之间细线 |
| 8 | 粗线 | 把有 DV 的成分和没有 DV 的成分分开。两类都存在时才需要 |
| 9 | 没有 Daily Value 的成分 | %DV 列放脚注符号 |
| 10 | 粗线 | 表格结束 |
| 11 | 脚注 | `† Daily Value not established.` 符号要和表里用的一致 |
| 12 | 外框 | 以上全部在一个细线方框内 |
| 13 | 成分表 | `Other Ingredients: ...` 紧贴方框**下方**（框外）。框内放不算严重问题，但默认按框外做 |

份量单位、表里的剂型、Other Ingredients 里的胶囊壳描述三者要一致（不能 Serving Size 写 Softgels、别处写 Capsules）。

## 2. 成分顺序

**有 DV 的**按 `daily-values.json` 的数组顺序排，不按来源表格的顺序、不按含量大小：

热量 → 总脂肪 → 饱和脂肪 → 反式脂肪 → 胆固醇 → 钠 → 总碳水 → 膳食纤维 → 总糖 → 添加糖 → 蛋白质 → 维生素 A、C、D、E、K → 硫胺素、核黄素、烟酸、B6、叶酸、B12、生物素、泛酸 → 胆碱 → 钙、铁、磷、碘、镁、锌、硒、铜、锰、铬、钼、氯、钾。

**没有 DV 的**（尿石素 A、NR、虾青素、植物提取物等）排在粗线之后。顺序法规没硬性规定，默认按含量从大到小；用户来源有明确的主次顺序就照来源。

## 3. %DV

- 计算：`含量 ÷ DV × 100`，四舍五入到整数百分比。
- 小于 1% 写 `<1%`。
- 没有 DV 的成分不写百分比，写脚注符号。
- 来源常见错误：把百分比写成小数（0.07）、少一位数（7% 应为 67%）、用了旧版 DV（如维生素 D 400 IU 体系）、用别国 NRV。
- **含量和 %DV 对不上时，两个数里至少有一个是错的，但不知道是哪个。** 面板上 %DV 填 `XX%`，含量照来源；清单里标 🔴，把两个方向都算出来给用户看（例：10 mg 维生素 E 标 7% → 按 10 mg 应为 67%；若 7% 是对的，含量应为 1 mg）。用户确认后再把 `XX%` 换成真值。
- 有 DV 的成分来源没给 %DV：同样填 `XX%`、标 🔴，清单里给出按含量算出的值。

## 4. 单位与数字

| 成分 | 必须用的单位 |
|---|---|
| 维生素 A | mcg RAE（不用 IU） |
| 维生素 D | mcg（可在括号里加 IU，如 `25 mcg (1,000 IU)`） |
| 维生素 E | mg（指 α-生育酚；不用 IU） |
| 叶酸 | mcg DFE，来自叶酸的写 `(xxx mcg folic acid)` |
| 烟酸 | mg NE |
| 其他 | g / mg / mcg |

- 用 `mcg`，不用 `μg`、`ug`。
- 数字和单位之间空一格：`250 mg`，不是 `250mg`。
- 千位可加逗号：`1,000 mg`。全表统一。
- 来源写 `1000mg`、`10 MG`、`90μg` 这类属于 🟢，直接规范。
- 来源用 IU 的属于 🔴：换算依赖成分形式，把换算结果和假设一起交给用户确认。

## 5. 成分名称与来源形式

- 维生素矿物质用 FDA 的名称（`Thiamin` 不是 `Thiamine`；`Vitamin B6`；`Folate`）。可在后面括号注明形式。
- **来源形式**应写在名称后的括号里：`Vitamin D3 (as cholecalciferol)`、`Calcium (from algae-derived mineral complex)`、`Magnesium (as magnesium glycinate)`。矿物质和大多数维生素缺来源形式 → 🟡，请用户提供，面板上先只写名称。
- **植物成分**：写常用名 + 使用部位，`Turmeric Root Extract`；非常用名要加拉丁学名。提取物有标准化的写出来：`(standardized to 95% curcuminoids)`。缺部位 → 🟡。
- **专利混合物**：写混合物名称和总重量，子成分缩进列在下面，按重量从大到小，子成分不必写各自重量；%DV 列用脚注符号。来源只给了子成分没给总重，或子成分顺序看不出依据 → 🟡。
- 商标原料（如 Mitopure®）：名称照来源，® ™ 保留。

## 6. 剂型决定要不要营养项

热量、脂肪、碳水、糖、蛋白质、钠只要达到可申报量就必须列，哪怕它们来自辅料。来源是"配方表"（只列活性成分）时最容易漏。

| 剂型 | 通常需要 | 判断线索 |
|---|---|---|
| 软糖 | Calories、Total Carbohydrate、Total Sugars（含糖时还要 Added Sugars）；可能有 Sodium | 每份克数 × 糖或糖醇占比。用糖醇（maltitol、sorbitol）的仍有热量和碳水 |
| 粉剂、饮品 | 同上，看配方 | 每勺克数 |
| 液体、含油软胶囊 | Calories、Total Fat | 每份油量达到 0.5 g 以上 |
| 普通胶囊、片剂 | 一般不需要 | 每份总重很小 |

可以省略的门槛：热量 < 5 kcal；脂肪、碳水、糖、蛋白质 < 0.5 g；钠 < 5 mg。

- **Sugar Alcohol 是自愿申报**，只有在包装上做了关于糖或糖醇的声明（如 Sugar Free）时才必须列。不要把它说成必填。
- 该有而来源没有 → 🔴。**不要估算后填进面板**，可以在清单里给出粗略量级帮用户判断（如"3 粒共 9 g、主料麦芽糖醇，热量大约 15–20 kcal，碳水约 6–8 g，需要工厂的检测值"）。

## 7. Other Ingredients

- 按用量从大到小排列。来源顺序看不出依据时照来源，不重排。
- 胶囊壳写法：`Vegan Softgel (Modified Food Starch, Glycerin, Purified Water)` 或直接把壳的成分并入列表。
- **香精**必须能分辨 `Natural Flavor` 还是 `Artificial Flavor`。来源只写 `Flavouring (Jasmine Flavour)` 不标性质 → 🟡，照抄不替用户定性。
- **色素**：写具体名称（`Beta-Carotene (Color)`、`FD&C Red No. 40`）。
- **明胶**：鱼来源涉及过敏原，来源没写出处 → 🟡。
- 八大过敏原 + 芝麻（乳、蛋、鱼、甲壳类、树坚果、花生、小麦、大豆、芝麻）：成分名里没有直接体现来源的，要加 `Contains: Soy.` 这类声明。
- 英式拼写改美式（flavour → flavor、colour → color、fibre → fiber）→ 🟢。
- 缺逗号、括号不配对、成分粘连（`Natural Flavouring (Grapefruit Flavour) Flavouring (Jasmine Flavour)`）→ 补标点属 🟢，但粘连处到底是一个成分还是两个要在清单里说明你的读法。
- 结尾加句号。

## 8. 算术自洽

- `Servings Per Container × Serving Size 数量 = 总粒数`。三个里有两个就能算第三个；三个都有但乘不上 → 🔴。
- 只有一个 → 缺的填 `XX`，🔴。
- 单粒重量 × 每份粒数应明显大于活性成分总和。活性成分加起来超过份重 → 🔴，来源有错。
- 同一成分在不同来源文件里数值不同 → 🔴，列出两处。

## 9. 缺陷检查表

逐项过，没问题的不写进清单。

**A 完整性**
- [ ] Serving Size 有数量和剂型单位
- [ ] Servings Per Container 有，或可由总粒数算出
- [ ] 每个成分有含量和单位
- [ ] 有 DV 的成分都有 %DV；没有 DV 的都有脚注符号和脚注
- [ ] 剂型需要的营养项齐全（§6）
- [ ] Other Ingredients 存在且看起来完整（有壳材、有赋形剂）

**B 数值**
- [ ] 每个 %DV 用现行 DV 重算一致（§3）
- [ ] 份数算术自洽（§8）
- [ ] 单位是 FDA 要求的那个（§4）
- [ ] 小数点、千位、量级没有明显笔误（1000 mg 的维生素 B12 这类）

**C 写法**
- [ ] 成分名是 FDA 名称；来源形式齐全且写法规范（§5）
- [ ] 植物成分有部位；提取物有规格
- [ ] 专利混合物有总重，子成分顺序合理
- [ ] 剂型用词全表一致
- [ ] 美式拼写；数字与单位间有空格；脚注符号统一

**D 顺序与结构**
- [ ] 有 DV 的成分按 §2 顺序
- [ ] 有 DV 与无 DV 之间有粗线
- [ ] Serving Size 在 Servings Per Container 上面
- [ ] 没有把赋形剂放进表里、把活性成分放进 Other Ingredients

**E 成分表**
- [ ] 香精、色素、明胶写法明确（§7）
- [ ] 过敏原声明
- [ ] 标点完整、成分不粘连

**F 面板外但值得提一句的**（只提醒，不处理）
- 矿物质的元素含量与剂型装量对不上：螯合物和有机酸盐的元素含量只有 7–16%（甘氨酸镁约 11–14%、牛磺酸镁约 9%、苹果酸镁约 15%、乳清酸镁约 7%、柠檬酸镁约 16%），标称的元素量除以这个比例就是所需原料重量，再和"每份粒数 × 单粒常见装量（0 号约 0.5 g，00 号约 0.75 g）"比。超出很多时提示用户核对是元素量还是化合物量
- 含量明显超过常见上限的成分（如维生素 D 250 mcg、锌 100 mg）
- 含量对功效成分来说低得不像实际配方的（可能单位写错）
- 表里出现 FDA 明确不允许作为膳食成分的物质
